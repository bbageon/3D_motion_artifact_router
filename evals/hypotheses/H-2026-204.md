# H-2026-204 — (H-2026-200 supersede, G1+G2 scope) Artifact-conditioned tool selection + closed-loop refinement 가 fixed post-processing 보다 NetGain 우위

## 본문 (등록 시점 그대로)

본 가설은 ArtifactRouter framework 의 Main RQ1 + RQ2 ([`docs/motion_research_strategy_summary.md §8`](../../docs/motion_research_strategy_summary.md)) 에 직접 매핑되며, [H-2026-200](H-2026-200.md) 의 supersede 이다. 핵심 research question 은 동일하나 **active scope 를 G1 + G2 (공식 MotionGPT)** 로 정정한다.

**Main RQ1 (artifact-conditioned selection)**: artifact 별 evaluator signal 을 기반으로 correction tool 을 선택하는 것이 fixed post-processing (global smoothing / fixed pipeline) 보다 효과적이다.

**Main RQ2 (closed-loop refinement)**: closed-loop tool-orchestrated refinement 는 single-step correction 또는 fixed pipeline 보다 **artifact reduction 과 motion fidelity preservation 사이의 trade-off** 를 더 잘 관리한다.

본 가설의 핵심 메시지: artifact 의 종류·body part·temporal region 이 다르므로, 단일 global post-processing 으로 균일 처리하기보다 artifact 상태에 따른 conditional tool selection + closed-loop re-evaluation 이 **net gain** 우위.

### supersede 사유 (H-2026-200 → H-2026-204)

본 프로젝트는 motion refinement framework (ArtifactRouter) 의 **독립 프로젝트** 이다. 이전 저장소 [`3D-Motion-Trajectory-prediction`](../../../3D-Motion-Trajectory-prediction/) 의 LLM-based motion generation 실험 (이전 저장소 가설 H-2026-101·102) 의 **후속 연구가 아니다**.

H-2026-200 의 `track_scope: [G1, G2, G3]` 중 G3 (이전 저장소의 Gemma 4 LoRA 자산) 는 본 프로젝트의 generator tier 가 아니므로 초기 등록 시 inadvertent inclusion (misregistration) 이다. 본 supersede 는 이를 정정한다. active scope: **G1 (diffusion-based: MDM / MLD) + G2 (공식 MotionGPT)**. 본 변경은 trial 0 / 결과 보기 전이므로 HARKing 비해당.

본 가설은 [H-2026-205](H-2026-205.md) (Learnable Routing) · [H-2026-206](H-2026-206.md) (Generator transfer) · [H-2026-203](H-2026-203.md) (No-harm) 의 부모 가설.

## 사전 정의

### 측정할 지표

[`reproducibility-checklist SKILL §3`](../../.claude/skills/reproducibility-checklist/SKILL.md) 정의 사전 단일 출처:

- **NetGain** (명세 §9.4):
  - `NetGain = ArtifactReduction - α·FidelityLoss - β·CorrectionMagnitude - γ·ToolCallCost`.
  - α, β, γ 는 synthetic injection protocol 의 perceptual rating 상관 최대화 grid search.
- **ArtifactReduction**: `TotalArtifactScore_before - TotalArtifactScore_after`.
- **FidelityLoss**:
  - Protocol A (synthetic injection): `MPJPE(refined, clean_GT) - MPJPE(corrupted, clean_GT)`.
  - Protocol B (generator output): `correction_magnitude + semantic_consistency_loss`.
  - Protocol C (distributional): FID_motion 변화.
- **CorrectionMagnitude**: `mean_{t,j} || p_refined - p_generated ||`.
- **ToolCallCost**: `number_of_tool_calls + iteration_count`.

### 임계 효과 크기

- Oracle best-tool vs fixed smoothing: NetGain median Δ ≥ +10% (명세 §11 Go 기준 5).
- Proposed orchestrator (rule-based) vs fixed smoothing: NetGain median Δ ≥ +5%, paired Wilcoxon p < 0.05, Cohen's d ≥ 0.3.
- Closed-loop vs single-step: NetGain median Δ ≥ +3% on **artifact-rich input** (G2 자연 분포 또는 synthetic injection Protocol A), paired Wilcoxon p < 0.05.

### 비교 대상

명세 §9.1 baseline:

- **B1**: Base generator only (no refinement).
- **B2**: Base + global smoothing.
- **B3**: Base + fixed correction pipeline.
- **B5**: Base + rule-based orchestrator (본 framework Phase 1).
- **B8**: Oracle best-tool (upper bound).

**Artifact-rich 입력원** (closed-loop vs single-step 비교의 dynamic range 제공):
- **Synthetic injection (Protocol A, 명세 §9.3)**: HumanML3D GT motion 에 controlled artifact 주입 → ground-truth-grounded artifact-rich 입력. 외부 generator 의존 없음.
- **G2 자연 artifact 분포 (Protocol B)**: 공식 MotionGPT 의 token boundary 불일치, sampling jitter 등.

trial ≥ 20 per (generator × baseline), generator quality-tier 최소 2개 (G1 + G2).

### 기각 조건 (다음 중 하나라도 충족)

1. 모든 correction tool 에서 target artifact 감소율 < 5%.
2. global smoothing (B2) 이 oracle best-tool (B8) 의 90% 이상 도달.
3. fixed pipeline (B3) 이 본 framework (B5) 와 비슷하거나 우세.
4. 모든 artifact type 에 단일 best tool 우세 (conditional selection 가치 부재).
5. closed-loop 가 single-step 대비 NetGain 차이 무의미 (Cohen's d < 0.1).

위 1-4 는 명세 §11 Stop 기준과 동일.

### 표본 요건

- trial ≥ 20 per (generator × baseline).
- generator quality-tier 최소 2개 (G1 + G2).
- n_seeds ≥ 3 if generator inference 가 stochastic (G1 diffusion · G2 sampling).
- 5 단계 비교 리포트 ([`eval-compare SKILL §6`](../../.claude/skills/eval-compare/SKILL.md)) 의 5단계 모두 충족.

## 평가 대상 산출물

- **generator (B1)**: G1 (MDM 또는 MLD) · G2 (공식 MotionGPT).
- **fixed smoothing (B2)**: SciPy `gaussian_filter1d` 또는 동등 (config hash 등록).
- **fixed pipeline (B3)**: foot_lock → smoothing → bone_projection 고정 순서.
- **rule-based orchestrator (B5)**: `orchestrator/rule_based.py` (KDG + scoring + artifact-tool compatibility matrix).
- **Oracle best-tool (B8)**: 각 sample 에 모든 correction tool 적용 후 best NetGain 선택.
- **사용 evaluator config / correction_tool config 의 hash** raw record 에 cross-link.
- **사용 split**: HumanML3D test split 의 일부 (synthetic injection Protocol A) + G2 inference output (Protocol B).
- **비교 절차**: [`eval-compare SKILL §6`](../../.claude/skills/eval-compare/SKILL.md) 5단계 리포트.

## Stage 정의

- **Stage 0** (MVP Week 1-2): HumanML3D GT motion + synthetic injection 으로 skeleton normalizer + evaluator + correction tool unit 검증. 외부 generator 불필요.
- **Stage 1** (MVP Week 3): single generator (G2 — 공식 MotionGPT) · multi-sample · 모든 tool 적용 후 oracle best-tool 식별. tool effect matrix 작성.
- **Stage 2** (MVP Week 4): G2 + fixed smoothing 비교 + synthetic injection 비교. NetGain Go 기준 (명세 §11) 정량 검증. G1 (MDM/MLD) 추가 도입 검토.
- **Stage 3** (post-MVP): multi-generator (G1 + G2) · n_seeds=3 · ≥ 20 trial 본격 학습.
