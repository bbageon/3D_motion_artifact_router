# H-2026-207 — (H-2026-204 supersede) Mechanism-targeted + generator/state-conditional refinement 가 품질을 개선한다 (Cat-A + blind 지각 통화)

## 본문 (등록 시점 그대로)

**주장**: post-generation refinement 는 (a) coordinate-level artifact score(증상)가 아니라 **생성 기전(mechanism — 예: root progression collapse)을 겨냥**할 때, (b) **generator/state 조건부로 적용**될 때 (deficit 있는 generator 에 apply / 없는 generator 에 STOP) motion 품질을 개선한다.

**평가 통화**: Category A 표준 지표 (R-Precision / MM-Dist / FID, equal-N·prompt-bootstrap) + **사전등록 blind 지각 A/B**. NetGain 등 Cat-C proxy 는 본 가설의 판정 통화가 아니다 (§3-20).

### ⚠️ Post-hoc registration 명시 (정직성 조항)

본 가설은 **지지 증거가 이미 존재하는 상태에서 등록**된다 (E8: MDM 기전 보정 — Cat-A 3지표 유의 개선 + blind 19/20; E10: VQ 고정 적용 시 Cat-A 악화 — 조건부 필요성. [P5 최종본](../reports/2026-07-12_poc_necessity_p1_p5.md)). 따라서 기존 증거는 본 가설의 **생성 근거이지 예측력 검증이 아니다**. supports 전환은 **독립 재현이 담당**한다 — 아래 사전 정의의 검증 표본은 전부 미실행 데이터.

### supersede 사유 (H-2026-204 → H-2026-207)

H-204 의 핵심 메시지("조건부 > 고정")는 유지되나: (1) 등록 통화 NetGain 이 사후 metric 게이트(§3-20)에서 Cat-C(내부 proxy)로 분류되어 판정 통화 자격 상실, (2) 상정 메커니즘(rule-based tool selection + closed-loop)이 실측에서 지각 개선 실패(E6), 실제 개선 경로는 기전-겨냥 보정(E8)으로 판명. 질문을 현재의 정당한 통화·실체로 재작성. 상세: [2026-07-13 가설 status 통합 검토](../reports/2026-07-13_hypothesis_status_review.md).

## 사전 정의

### 측정할 지표

- **Cat-A**: R-Precision top-1/2/3 · MM-Dist · FID (HumanML3D tm2t evaluator 계열; equal-N, prompt 단위 seed 처리, prompt-bootstrap B=1000, R-Prec 은 one-seed-per-prompt).
- **지각**: 사전등록 blind A/B (2AFC, 실속도, 좌우 무작위, answer key 분리, 이항 양측).
- **물리 (보조)**: foot_skate_world 등 Cat-B — 보고만, 단독 판정 금지.

### 지지 조건 (독립 재현 표본에서 — 다음 중 하나 이상)

1. **독립 pool 재현** (AR-024: 새 seed generation pool): 기전 보정이 deficit generator 에서 Cat-A ≥2/3 지표 유의 개선 **그리고** 비-deficit generator 고정 적용 시 Cat-A 유의 악화 (조건부 필요성 재현).
2. **타 데이터셋 재현** (AR-067 KIT-ML): 동일 방향 재현.
3. **타 diffusion 재현** (AR-080 MLD): root collapse 존재 시 동일 처방 방향 재현.
- 지각 claim 동반 시: blind A/B ≥15/20 (b1) — 외부 공개급은 b2/b3 (3+ raters).

### 기각 조건 (다음 중 하나라도 — 독립 재현 표본에서)

1. 기전 보정이 deficit generator 에서 Cat-A 개선 없음 (3지표 모두 CI 가 0 포함 또는 악화).
2. 조건부와 고정 적용의 차이 소멸 (비-deficit generator 에서도 개선 — 고정 적용으로 충분).
3. blind A/B ≤12/20 (지각 회복 재현 실패).

### 표본 요건

- 독립 재현 표본 = 본 가설 등록 전 미측정 데이터만 (기존 pool 재분석 불인정).
- generator ≥2 (deficit 1 + 비-deficit 1), prompt ≥100 (locomotion), seed ≥3.
- 5단계 비교 리포트 + §3-15 metadata.

## 평가 대상 산출물

- **기전 보정**: [RootGaitConsistencyTool](../../correction_tools/root_gait_consistency_tool.py) (contact-consistent root solve, GT-free) — config hash 기록.
- **조건부 적용 규칙**: generator-level (deficit 실측 기준) — per-motion gate 는 본 가설 범위 밖 (H-205 계열).
- 비교: 고정 적용 (전 generator 무조건) vs 조건부 vs 무개입.
