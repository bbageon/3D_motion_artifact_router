# H-2026-203 — (secondary) High-quality generator output 에 대해 No-harm 운영 — 분포·semantic·fidelity 훼손 없음

## 본문 (등록 시점 그대로)

본 가설은 ArtifactRouter framework 의 H3 (No-harm operating regime) ([`docs/motion_research_strategy_summary.md §4.1`](../../docs/motion_research_strategy_summary.md)) 에 매핑된다. Main RQ 가 아닌 **deployment-oriented safety analysis** — 본격 학습 entry 의 필수 조건은 아니나 production 가능성 검증에 핵심.

**H3 (No-harm)**: 학습된 라우팅이 artifact-rich motion 을 의미 있게 개선하면서도, 이미 품질이 높은 motion 에 대해서는 (적절히 STOP 하거나 small-strength 로 수렴함으로써) 분포·의미·fidelity 를 훼손하지 않는다.

본 가설은 [H-2026-200](H-2026-200.md) 의 secondary supporting evidence. supports 시 본 framework 의 "보정해야 할 때만 보정한다" 운영 특성을 정량 입증.

## 사전 정의

### 측정할 지표

- **FID_motion**: refined motion 분포 vs original GT motion 분포 의 Fréchet distance.
- **FGD**: Fréchet Gesture Distance.
- **MM-Dist**: text-motion multimodal distance (text-to-motion case).
- **Diversity**: refined motion 간 latent feature pairwise distance.
- **CorrectionMagnitude** (Protocol B).
- **User study non-inferiority margin δ** — refined vs original preference rate.

### 임계 효과 크기 (non-inferiority margin)

- FID_motion 변화 ≤ +ε (사전 등록 ε, 분포 손상 없음).
  - default ε = baseline FID_motion 의 5%.
- CorrectionMagnitude 평균 ≤ low threshold (예: 0.01m).
- Modified frame ratio ≤ 20% (대부분 frame 미수정).
- User study: refined 가 original 대비 통계적으로 유의미하게 낮게 평가되지 않음 (Wilcoxon p > 0.05, 또는 preference rate 0.5 ± δ 안쪽, δ = 0.10).

### 비교 대상

- **G1 input → G1 output (original)**: no-refinement.
- **G1 input → ArtifactRouter output**: refined.
- **G1 input → fixed smoothing output**: B2 baseline.

trial ≥ 50 on G1 (high-quality), user study sample ≥ 20.

### 기각 조건

1. FID_motion 변화 > +5% baseline.
2. CorrectionMagnitude > 0.01m on G1.
3. Modified frame ratio > 30% on G1 (대부분 frame 수정 = 과수정).
4. User study: refined 가 original 보다 통계적으로 유의미하게 낮게 평가 (preference rate < 0.5 - δ).
5. Diversity 감소 > 10% (motion mode collapse 신호).

위 1-5 중 하나라도 충족하면 H-2026-203 contradicts — ArtifactRouter 의 selector 가 high-quality input 에서 적절히 STOP 또는 small-strength 로 수렴 못 함.

### 표본 요건

- G1 generator 의 다양한 motion category sample ≥ 50.
- user study participant ≥ 10, sample per participant ≥ 20.
- n_seeds ≥ 3 (selector 학습 stochastic).

## 평가 대상 산출물

- **G1 generator**: MDM 또는 MLD (high-quality SOTA).
- **ArtifactRouter (B6 learned orchestrator)**: H-2026-201 supports 후의 학습된 selector.
- **Fixed smoothing (B2)**: comparison.
- **User study tool**: `tools/perceptual_rating_collector.py` (명세 §9.3 Protocol B).
- **분포 비교 metric**: FID_motion 계산 코드 + reference 분포.

## Stage 정의

- **Stage 0** (Post-MVP, H-2026-201 supports 후): G1 sample 50개에 본 framework 적용 후 FID_motion + CorrectionMagnitude + Modified frame ratio 측정.
- **Stage 1**: user study 진행 (≥ 20 sample, ≥ 10 participant).
- **Stage 2**: 분포 + sample + perceptual 종합 No-harm 판정.
