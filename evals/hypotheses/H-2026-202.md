# H-2026-202 — 학습된 selector 가 새로운 generator output 에 대해서도 generator-agnostic 일반화 가능

## 본문 (등록 시점 그대로)

본 가설은 ArtifactRouter framework 의 Main RQ4 ([`docs/motion_research_strategy_summary.md §8`](../../docs/motion_research_strategy_summary.md)) 에 매핑된다.

**Main RQ4 (Generator-agnostic 일반화)**: 제안 framework 는 서로 다른 generator output 에서도 적용 가능한 generator-agnostic 특성을 보인다. zero-shot transfer 와 small-calibration transfer 를 함께 확인.

본 가설은 [H-2026-201](H-2026-201.md) 의 supports 가 선행 조건 (learnable routing 자체가 가치 있음이 입증된 후에 transfer 평가 의미 있음).

본 가설의 정량 메시지: generator A 에서 학습한 selector 가 generator B 의 output 에 적용될 때 (zero-shot) NetGain 손실이 적고, 소량 calibration (예: 10-30 sample 의 generator B 의 oracle label 로 fine-tune) 후 NetGain 회복 가능.

## 사전 정의

### 측정할 지표

- **Transfer NetGain ratio**: `NetGain(trained on A, applied to B) / NetGain(trained on B, applied to B)`. 1.0 = perfect transfer, 0 = no transfer.
- **Zero-shot transfer gap**: `NetGain(B-trained on B) - NetGain(trained on A, applied to B)`.
- **Small-calibration transfer gap**: `NetGain(B-trained on B) - NetGain(A-trained + small-calibration on B)`.

### 임계 효과 크기

- **Zero-shot transfer ratio ≥ 0.7** — generator A learned selector 가 generator B 에서 70% 이상 NetGain 보존.
- **Small-calibration transfer ratio ≥ 0.9** — 10-30 sample calibration 후 90% 이상 회복.
- **paired Wilcoxon p < 0.05** for zero-shot vs random-decision baseline (transfer 가 random 보다 의미 있음).

### 비교 대상

- **Selector trained on G3 → applied to G1** (legacy → high-quality).
- **Selector trained on G1 → applied to G3** (high-quality → legacy).
- **Selector trained on G2 → applied to G1/G3** (token-based → others).
- **Random decision baseline**.
- **Generator-specific selector** (each generator 의 own oracle label 로 학습) — upper bound.

trial ≥ 20 per (source generator × target generator pair × seed).

### 기각 조건

1. Zero-shot transfer ratio < 0.5 (대부분의 NetGain 손실).
2. Small-calibration transfer ratio < 0.7.
3. Zero-shot 이 random decision baseline 과 통계적으로 구분 안 됨 (Wilcoxon p > 0.1).
4. Transfer direction (A→B) 이 (B→A) 와 비대칭이며 본질적 이유 식별 불가 (transfer 가 unstable).

### 표본 요건

- 최소 3 generator pair (G1↔G3 + G1↔G2 + G2↔G3).
- trial ≥ 20 per pair · 3 seeds.
- 5단계 비교 리포트.

## 평가 대상 산출물

- **Source-trained selector**: `orchestrator/contextual_bandit_<src_gen>.pt` 등 (가중치 hash 포함).
- **Calibration script**: `experiments/transfer_calibration.py` (10-30 sample 로 fine-tune).
- **Target-trained baseline selector**: comparison.
- **Random decision baseline**.
- 사용 evaluator/correction_tool/orchestrator config hash raw record cross-link.

## Stage 정의

- **Stage 0** (Post H-2026-201 supports): G3 → G1 zero-shot transfer 평가.
- **Stage 1**: G1 → G3 reverse direction.
- **Stage 2**: 모든 pair (G1↔G2, G2↔G3 등) + small-calibration.
