# H-2026-205 — (H-2026-201 supersede, G1+G2 scope) Learnable Routing — supervised/contextual-bandit (RL-style) selector 가 rule-based baseline 대비 net gain 의미 있게 개선

## 본문 (등록 시점 그대로)

본 가설은 ArtifactRouter framework 의 Main RQ3 ([`docs/motion_research_strategy_summary.md §8`](../../docs/motion_research_strategy_summary.md)) 에 매핑되며, [H-2026-201](H-2026-201.md) 의 supersede 이다. core RQ 는 동일하나 **active scope 를 G1 + G2 로 정정** 하고, **본 프로젝트의 1차 contribution 이 강화학습 기반 refinement 임을 명시** 한다.

**Main RQ3 (Learnable Routing)**: artifact state → correction action 매핑을 학습 가능한 routing 문제로 정식화 — `π*(a | s)` 가 데이터 기반으로 학습 가능한지 검증한다. 특히 learned selector (contextual-bandit 은 RL 의 단일-step 특수 case) 가 rule-based baseline 대비 net gain 을 개선하고, 새로운 generator output 에서도 일정 수준의 일반화 성능을 보이는지 확인.

본 프로젝트의 framing: **본 연구의 핵심 contribution 은 강화학습 기반 refinement** 이다. generation 단계의 motion quality 개선은 본 연구의 contribution 이 아니며, 따라서 generation 은 검증된 외부 generator (G1 diffusion · G2 공식 MotionGPT) 의 output 만 사용한다.

본 가설은 [H-2026-204](H-2026-204.md) 의 supports 가 선행 조건 (rule-based orchestrator 가 fixed post-processing 보다 우위인 baseline 이 확립되어야 learnable routing 의 추가 가치 측정 가능).

본 가설의 정량 메시지: **rule-based 와 oracle best-tool 사이의 gap 을 learned selector 가 부분적으로 채운다**. Oracle (B8) - rule-based (B5) gap 이 작으면 learnable routing 의 가치 부재 (stop signal).

### supersede 사유 (H-2026-201 → H-2026-205)

[H-2026-204](H-2026-204.md) 와 동일 사유: 본 프로젝트는 독립 프로젝트이며 이전 저장소의 LLM motion generation 후속이 아니다. G3 misregistration 정정. 본 가설은 H-2026-204 의 supports 가 선행 조건이므로 동일 active scope (G1 + G2) 를 상속한다.

## 사전 정의

### 측정할 지표

- **NetGain** (정의 H-2026-204 참조).
- **Oracle gap closure rate**: `(NetGain_learned - NetGain_rule_based) / (NetGain_oracle - NetGain_rule_based)`. 0 = rule-based 와 동등, 1 = oracle 과 동등.
- **Decision agreement rate**: learned selector 와 oracle best-tool 의 decision 일치 비율.

### 임계 효과 크기

- Learned selector (B6) vs rule-based (B5): NetGain median Δ ≥ +5%, paired Wilcoxon p < 0.05, Cohen's d ≥ 0.3.
- Oracle gap closure rate ≥ 30%.
- Decision agreement rate ≥ 50% (random baseline 11% — 9 tool 중 1 — 대비 의미 있는 신호).

### 비교 대상

명세 §9.1 baseline:

- **B5**: Base + rule-based orchestrator.
- **B6**: Base + learned/contextual-bandit orchestrator (RL-style).
- **B7**: Base + proposed orchestrator + learned calibrator as optional tool.
- **B8**: Oracle best-tool (upper bound).

trial ≥ 30 per (generator × baseline) — learned selector 학습 표본 + evaluation 표본 분리.

### 기각 조건 (다음 중 하나라도 충족)

1. Oracle (B8) - rule-based (B5) gap 이 작음 (NetGain Δ < 5%) — learnable routing 가치 부재.
2. Learned selector (B6) 가 rule-based (B5) 와 동등 (paired Wilcoxon p > 0.1).
3. Learned selector 가 oracle 의 < 10% gap 만 채움.
4. Decision agreement rate < 25%.

### 표본 요건

- trial ≥ 30 per (generator × baseline).
- learned selector 학습용 별도 split (예: 70% train · 30% eval). evaluation 은 별도 hold-out.
- n_seeds ≥ 3 (learned selector 학습 stochastic).
- 5단계 비교 리포트 모든 단계 충족.

## 평가 대상 산출물

- **rule-based orchestrator (B5)**: `orchestrator/rule_based.py`.
- **supervised selector (B6 - supervised)**: `orchestrator/supervised_selector.py` (oracle best-tool label 로 학습).
- **contextual-bandit / RL selector (B6 - bandit)**: `orchestrator/contextual_bandit.py` (LinUCB 또는 Thompson sampling 우선, full RL 본격화는 후속 가설로).
- **learned calibrator plug-in (B7)**: `correction_tools/learned_calibrator_tool.py` (DMC 또는 동등).
- **Oracle (B8)**: 모든 tool 적용 후 NetGain best 선택.
- **사용 generator**: G1 + G2 (공식 MotionGPT).
- **사용 split**: HumanML3D test split + synthetic injection.
- **평가 메트릭**: NetGain · Oracle gap closure · Decision agreement.

## Stage 정의

- **Stage 0** (Post-MVP Phase 2): oracle best-tool label 생성 (모든 sample 에 모든 tool 적용 후 best 선택). supervised selector 학습 + evaluation.
- **Stage 1**: contextual-bandit (LinUCB) 학습 + evaluation.
- **Stage 2**: 두 algorithm 통합 비교 + generator transfer ([H-2026-206](H-2026-206.md)) 결합.
