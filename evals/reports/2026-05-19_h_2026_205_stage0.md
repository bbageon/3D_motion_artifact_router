# eval-compare — 2026-05-19 — H-2026-205 Stage 0 (Supervised Selector vs Rule-based / Fixed / Oracle)

본 리포트는 [`eval-compare SKILL §6`](../../.claude/skills/eval-compare/SKILL.md) 의 5단계 형식을 따른다.

> **범위 한정**: 본 리포트는 [H-2026-205](../hypotheses/H-2026-205.md) **Stage 0** (supervised selector from B8 oracle labels) 의 measurement. Stage 1 (contextual bandit) 및 Stage 2 (generator transfer 결합) 는 후속.
>
> **선행 motivation**: [B5 negative result](2026-05-19_h_2026_204_rq1_threshold_2.md) 의 부록 E-F — B5 (rule-based) 가 B2 (fixed smoothing) 를 능가 불가능 → **learnable signal 필요** 의 직접 motivation.

## 1. 제시한 가설

[H-2026-205](../hypotheses/H-2026-205.md) — **Learnable Routing**: artifact state → correction action 매핑을 학습 가능한 routing 문제로 정식화. supervised / contextual-bandit selector 가 rule-based baseline 대비 net gain 의미 있게 개선.

### 사전 등록 임계 (H-2026-205 §사전 정의)

| 임계 | 내용 |
|---|---|
| **1. NetGain median Δ ≥ +5%** | B6 (learned) vs B5 (rule-based) |
| **2. p < 0.05** | paired Wilcoxon signed-rank |
| **3. Cohen's d ≥ 0.3** | paired effect size |
| **4. Oracle gap closure rate ≥ 30%** | `(B6 - B5) / (B8 - B5)` |
| **5. Decision agreement rate ≥ 50%** | B6 prediction vs B8 oracle best |

세 임계 (1-3) 모두 충족 + 4, 5 충족 시 **supports**. 일부 미충족 시 inconclusive 또는 contradicts.

### Training data (B6)

[`evals/snapshots/oracle_training_data_v1.json`](../snapshots/oracle_training_data_v1.json):
- **Source**: oracle_single_step_v2 raw records (30 sample × 3 artifact = 90 tuples).
- **State features (6-dim)**:
  - artifact_kind one-hot (3): foot_floating / bone_stretch_right_arm / global_jitter.
  - corrupted motion 의 evaluator max scores (3): FootFloating / BoneLength / VelocityJitter.
- **Labels**:
  - best_tool (3-class): FootLockTool / BoneProjectionTool / VelocitySmoothingTool.
  - best_strength (3-class): small / medium / large.
- **Label distribution**:
  - tool: 100% artifact_kind 로 결정 (foot→FL, bone→BP, jitter→VS, 각 30).
  - strength: medium=21, large=67, small=2 (foot 만 variable, 나머지 거의 large).

- **train_ratio = 0.7**, **seed = 42**, **sample 단위 disjoint** (같은 trial_id 가 train + eval 에 안 겹침).
- 21 trial → train, 9 trial → eval.
- 63 train tuples, 27 eval tuples (3 artifact × 9 trials).
- split_id: `supervised_eval_v1` (raw record 박제).

### Model

- **type**: scikit-learn `RandomForestClassifier(n_estimators=50, max_depth=5, random_state=42)`.
- **two independent classifiers**: tool_clf + strength_clf.
- **target_part**: `ARTIFACT_TO_TARGET_PART` lookup (foot→both_feet, bone→right_arm, jitter→full_body).

### NetGain calibration

- `calibrated_protocol_a_v1` (α=5.0, β=0.0, γ=0.0).

3. **rule_tool_learned_strength = baseline 동일** — tool 학습은 무가치 (artifact_kind → tool 의 deterministic rule 매핑으로 100% 정확).

### E-3. 학습 신호의 source isolation

본 ablation 의 결정적 결론:

> **B6 supervised 의 학습 가치는 100% strength prediction 에 집중**.

- Tool selection: artifact_kind 또는 evaluator scores 로 trivially 100% 결정 가능 — 학습 무가치.
- Strength selection: 84-86% accuracy — 학습 가치의 source.
- Strength prediction = 데이터 기반 SEVERITY_TO_STRENGTH mapping refinement. rule_based 의 hand-coded (low→small, medium→medium, high→large) 보다 oracle 의 실제 best strength 분포를 학습.

### E-4. 학술적 함의

본 ablation 은 H-2026-205 의 framing 을 정밀화:
- **"artifact state → correction action" 의 학습성** 은 tool selection (trivial) + strength selection (non-trivial) 의 **strength 측면에서만 정량 의미** 있음.
- contextual bandit / RL 의 가치도 strength selection 에 집중될 것 — Stage 1 의 algorithm 선택 시 strength action space 우선.
- 단, 본 결론은 single-artifact synthetic setting 한정. multi-artifact / G2 natural 에서는 tool selection 의 trivial 성이 깨질 수 있음 (multi-artifact 의 dominant artifact identification 이 non-trivial).

ablation 결과로 다음 step 의 의미 정밀화:

### N-2. 5단계 — 실험 평가

#### G2 natural sequence oracle (n=50)

- 대상: G2 generated motion 50 개 (`external_assets/g2_generated_v1/motion_001-050.npy`), synthetic injection 없음 (G2 motion 자체가 corrupted).
- Search: DFS exhaustive, max_depth K=5, action space = 10 (STOP + 3 tool × 3 strength).
- Pruning: AGENTS.md §3-4 일관 (Score 비감소 + same-pair strength decay).
- NetGain (**Protocol B simplified**, Step 5/5-B 일관):

- Comparison baseline: B2 G2 v2 (n=50, 재실행, [`evals/snapshots/baseline_b2_fixed_smoothing_g2_v2.json`](../snapshots/baseline_b2_fixed_smoothing_g2_v2.json)).

**결론** (사용자 directive 의 분기점 종합 정답):
- **"B2 를 넘는 sequence 가 실제 존재" — synthetic + G2 모두에서 YES** (paired Wilcoxon p<1e-9 양쪽 모두).
- **단 mechanism 이 distribution 별로 다름**:
  - Synthetic: **genuine multi-step** (best_length=5 dominant, large→small decay sequence).
  - G2: **STOP-dominant abstain** (best_length=0 dominant, minimal correction).
- **RL-1 의 정확한 form** = "(sequence oracle imitation) + (abstain learning)" — STOP 도 action 의 하나로 학습.

### N-5. G2 의 STOP-dominant mechanism (정밀)

- **G2 natural severity 가 small/medium 분포** (Step 5-B oracle data v2 의 86% small strength). 이미 generation 단계에서 어느 정도 smooth → correction tool 의 ROI 마진 작음.
- **B2 (fixed medium smoothing) 가 모든 G2 motion 에 medium-strength VelocitySmoothing 강제** — sample 의 절반 이상에서 over-modification (NetGain -0.013 median).
- **Sequence oracle 의 best policy**:
  - 54% sample: **STOP** (B2 와 같은 ToolSet 을 가지고도 do-nothing 이 더 우월).
  - 46% sample (23/50): 1-2 step minimal correction. 첫 action = FL/small 또는 BP/small, 그 다음 STOP.
- → **abstain decision (STOP)** 이 G2 의 핵심 — non-STOP action 의 NetGain 우위는 marginal.

이는 **H-2026-203 (No-harm)** 의 정식 evidence — High-quality generator (G2 = MotionGPT pretrained) 의 output 에 대해서는 abstain 능력이 critical.

### N-7. Caveats (잔여)

1. **G2 의 absolute NetGain 작음**: G2 sequence oracle mean +0.011 — magnitude 자체 작음. perceptual significance 별도 확인 필요 (사용자 plan 의 step 5).
2. **B2 G2 의 over-modification**: B2 가 negative NetGain 인 이유는 G2 의 natural smoothness → medium smoothing 이 fidelity penalty 더 큼. tool registry / strength default 의 G2 adaptation 가능성도 있음.
3. **G2 split 의 calibration leakage**: G2 oracle training data v2 (Step 5-B v2) 와 본 G2 sequence oracle 이 같은 50 motion 사용. 학습된 RL-1 의 평가는 별도 split 또는 K-fold 필요 (AGENTS.md §3-15 split_id 박제 의무).
4. **K=10 subset 의 n=10 small**: K=5 binding 진단의 statistical n 작음 (10). best_length=6 이 2/10 (20%) 이지만 sample size 한계 인식 (CI 넓음). full K=10 (n=30) 측정 가능 — 단 추가 compute 4-8x.

### N-8. 다음 step plan — RL-1 sequence oracle imitation (사용자 directive 정확)

사용자 roadmap (2026-05-25 본 directive):
> "RL-1은 Q-learning부터 복잡하게 가기보다는, 저는 sequence-oracle imitation을 먼저 추천합니다. 즉:
> - sequence oracle이 고른 action sequence를 label로 삼고
> - state → next action을 지도학습으로 배우기
> 이게 Q-learning보다 안정적이고, 지금 이미 oracle 데이터를 만들었기 때문에 바로 연결됩니다."

| Order | Step | 의미 | 본 부록 N 의 결과와 연결 |
|---|---|---|---|
| 3 | **RL-1: sequence oracle imitation** | (state_t, action_t) pair 를 oracle best path 에서 추출 → supervised state→next_action 학습. **STOP 도 action**. | **synthetic + G2 의 oracle data 모두 사용** (multi-distribution training). best path 의 STOP/non-STOP mix 가 abstain learning 의 자연스러운 supervision. |
| 4 | RL-2: Q-learning / value iteration | imitation 이 ceiling 못 따라가면 진행. | imitation 의 sample efficiency 가 충분하지 않을 때만. |
| 5 | Perceptual rating | 최종 후보 policy 가 생긴 뒤. | NetGain proxy 의 perceptual validity (synthetic + G2 모두). |

**RL-1 sequence oracle imitation 의 구체 design** (다음 step):
- Training data:
  - Synthetic multi-artifact (n=30) 의 best path (부록 M).
  - G2 natural (n=50) 의 best path (부록 N).
- State: 6-dim (artifact_kind onehot + 3 evaluator max scores) — 또는 더 rich state (best path step 의 evolved state 도 포함).
- Action space: **11 actions** = STOP + 9 (tool × strength). STOP 학습 정식 추가.
- Model: SupervisedSelector 확장 (action_clf 가 11-class, 또는 (tool_clf 4-class incl STOP) × (strength_clf 3-class)).
- Eval: per-step closed-loop 의 NetGain vs sequence oracle ceiling.
