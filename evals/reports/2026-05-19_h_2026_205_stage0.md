# eval-compare — 2026-05-19 — H-2026-205 Stage 0 (Supervised Selector vs Rule-based / Fixed / Oracle)

본 리포트는 [`eval-compare SKILL §6`](../../.claude/skills/eval-compare/SKILL.md) 의 5단계 형식을 따른다.

> **범위 한정**: 본 리포트는 [H-2026-205](../hypotheses/H-2026-205.md) **Stage 0** (supervised selector from B8 oracle labels) 의 measurement. Stage 1 (contextual bandit) 및 Stage 2 (generator transfer 결합) 는 후속.
>
> **선행 motivation**: [B5 negative result](2026-05-19_h_2026_204_rq1_threshold_2.md) 의 부록 E-F — B5 (rule-based) 가 B2 (fixed smoothing) 를 능가 불가능 → **learnable signal 필요** 의 직접 motivation.

---

## 1. 제시한 가설

[H-2026-205](../hypotheses/H-2026-205.md) — **Learnable Routing**: artifact state → correction action 매핑을 학습 가능한 routing 문제로 정식화. supervised / contextual-bandit selector 가 rule-based baseline 대비 net gain 의미 있게 개선.

### 사전 등록 임계 (H-2026-205 §사전 정의)

| 임계 | 내용 |
|---|---|
| **1. NetGain median Δ ≥ +5%** | B6 (learned) vs B5 (rule-based) |
| **2. p < 0.05** | paired Wilcoxon signed-rank |
| **3. Cohen's d ≥ 0.3** | paired effect size |
| **4. Oracle gap closure rate ≥ 30%** | `(B6 - B5) / (B8 - B5)` |
| **5. Decision agreement rate ≥ 50%** | B6 prediction vs B8 oracle best |

세 임계 (1-3) 모두 충족 + 4, 5 충족 시 **supports**. 일부 미충족 시 inconclusive 또는 contradicts.

### Training data (B6)

[`evals/snapshots/oracle_training_data_v1.json`](../snapshots/oracle_training_data_v1.json):
- **Source**: oracle_single_step_v2 raw records (30 sample × 3 artifact = 90 tuples).
- **State features (6-dim)**:
  - artifact_kind one-hot (3): foot_floating / bone_stretch_right_arm / global_jitter.
  - corrupted motion 의 evaluator max scores (3): FootFloating / BoneLength / VelocityJitter.
- **Labels**:
  - best_tool (3-class): FootLockTool / BoneProjectionTool / VelocitySmoothingTool.
  - best_strength (3-class): small / medium / large.
- **Label distribution**:
  - tool: 100% artifact_kind 로 결정 (foot→FL, bone→BP, jitter→VS, 각 30).
  - strength: medium=21, large=67, small=2 (foot 만 variable, 나머지 거의 large).

### Train/eval split

- **train_ratio = 0.7**, **seed = 42**, **sample 단위 disjoint** (같은 trial_id 가 train + eval 에 안 겹침).
- 21 trial → train, 9 trial → eval.
- 63 train tuples, 27 eval tuples (3 artifact × 9 trials).
- split_id: `supervised_eval_v1` (raw record 박제).

### Model

- **type**: scikit-learn `RandomForestClassifier(n_estimators=50, max_depth=5, random_state=42)`.
- **two independent classifiers**: tool_clf + strength_clf.
- **target_part**: `ARTIFACT_TO_TARGET_PART` lookup (foot→both_feet, bone→right_arm, jitter→full_body).

### NetGain calibration

- `calibrated_protocol_a_v1` (α=5.0, β=0.0, γ=0.0).

## 3. 실험적 근거

### 3-1. Model train/eval accuracy

| Metric | Train (n=63) | Eval (n=27) |
|---|---|---|
| tool_accuracy | 100% | **100%** |
| strength_accuracy | 98.4% | **88.9%** |
| joint_accuracy | n/a | **88.9%** |

→ tool prediction 은 trivially perfect (artifact_kind 가 100% determinative).
→ strength prediction 의 24/27 정확 — foot 의 medium/large 차등을 evaluator score 로 부분 학습.

### 3-2. Per-artifact NetGain median 비교

| Artifact | B6 supervised | B5 v3 | B2 | B8 oracle |
|---|---|---|---|---|
| bone | **+0.187 (large 9/9)** | +0.187 | +0.00004 | +0.187 |
| foot | **+0.487 (medium 7 + large 2)** | -0.067 | +0.0037 | +0.487 |
| jitter | **+0.436 (large 9/9)** | +0.356 | +0.356 | +0.436 |

**핵심 관측**:
- bone: B6 = B5 = B8 (모두 +0.187). 학습 가치 0 (B5 v3 도 이미 oracle 수준).
- foot: B5/B2 가 거의 0 → B6 가 **oracle 수준** (+0.487) 도달. 결정적 차이.
- jitter: B5/B2 의 +0.356 (medium strength) → B6 의 **+0.436 (large strength 학습)**. B2 가 능가 못 한 부분.

### 3-3. Paired test (3-way)

|---|---|---|---|---|
| bone | +0.00000 | +0.0% | 1.0 | +0.00 (tie) |

| jitter | **+0.080** | +22.6% | **2.0e-03** | **+2.74** (huge) |
| **POOLED** | **+0.077** | n/a | **1.17e-04** | **+0.55** (medium) |

#### B6 vs B2

| Artifact | Δ median | Δ% | p (greater) | Cohen's d |
|---|---|---|---|---|
| bone | +0.140 | +24,199% | **2.0e-03** | **+6.46** (huge) |
| foot | +0.486 | +13,184% | **5.9e-03** | **+1.17** (huge) |
| jitter | +0.080 | +22.6% | **2.0e-03** | **+2.74** (huge) |
| **POOLED** | **+0.139** | n/a | **2.76e-06** | **+0.90** (huge) |

#### B6 vs B8 oracle (oracle gap closure)

| Artifact | Δ median (B8 - B6) | p (greater) | Cohen's d |
|---|---|---|---|
| bone | +0.000 | 1.0 | +0.000 |
| foot | +0.000 | 0.125 | +0.339 |

→ **B6 가 oracle 과 거의 동등** (Pooled Δ ≈ 0, Cohen's d=+0.20 small effect).

### 3-4. Oracle gap closure rate (사전 등록 임계 4)

`(NetGain_B6 - NetGain_B5) / (NetGain_B8 - NetGain_B5)`:

| Artifact | B5 | B6 | B8 | Closure rate |
|---|---|---|---|---|
| bone | +0.187 | +0.187 | +0.187 | n/a (denom 0) |
| **foot** | -0.067 | +0.487 | +0.487 | **100%** (full closure) |
| **jitter** | +0.356 | +0.436 | +0.436 | **100%** (full closure) |

→ **B6 가 foot, jitter 에서 oracle gap 의 100% close**. 임계 30% 압도적 충족.

### 3-5. Decision agreement rate (사전 등록 임계 5)

- **Joint accuracy on eval set: 88.9%** (24/27 correct (tool, strength) pairs).
- random baseline (9-class uniform): 11%.
- **임계 50% 압도적 충족**.

#### Stage 0 한계 (caveat)

- **n_eval = 27 (사전 임계 trial ≥ 30 미달)**. 본 prototype 의 표본 부족 — Stage 1 (contextual bandit) 또는 Stage 2 (확장 trial) 에서 trial ≥ 30 보강 필요.
- **Single seed** (random_state=42). n_seeds ≥ 3 의 robust 검증 후속.
- **Single-artifact synthetic only**: multi-artifact / G2 natural artifact 후속 검증.
- **Calibration α=5.0 (provisional)**: magnitude 는 calibration 종속 ([2026-05-19c §2-2](../../reports/2026-05-19c.md)).
- **B6 supervised 의 학습 데이터가 oracle 의 best label**: 본질적으로 B6 의 ceiling = oracle. eval 의 closure 100% 는 B6 가 oracle 의 mapping 을 정확히 학습. 향후 novel sample (training 외) 에서의 일반화는 후속.
