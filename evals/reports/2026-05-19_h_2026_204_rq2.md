## 1. 제시한 가설

본 비교는 다음 활성 가설의 일부 RQ 를 평가한다.

- [H-2026-204](../hypotheses/H-2026-204.md) **RQ2** — closed-loop tool-orchestrated refinement 는 single-step correction 보다 **artifact reduction 과 motion fidelity preservation 사이의 trade-off** 를 더 잘 관리한다.

가설 본문의 사전 등록 threshold (등록 2026-05-15):
- **NetGain median Δ ≥ +3% on artifact-rich input** (synthetic injection Protocol A 또는 G2 자연 분포).
- **paired Wilcoxon p < 0.05**.
- **Cohen's d ≥ 0.1** (보수적).

위 세 조건 모두 충족 시 supports, 일부 미달 시 inconclusive 또는 partial supports, 모두 미달 시 contradicts.

## 4. 가설 평가

### H-2026-204 RQ2 — closed-loop refinement ≥ single-step

#### 판정: **partial supports** — direction 충족, magnitude 부분 미달.

#### 정량 근거

사전 등록 3 threshold 각각:

1. **Paired Wilcoxon p < 0.05**: ✓
   - per-artifact: p ∈ [9.31e-10, 2.00e-05], 모두 p < 1e-04.
   - pooled: p = 3.77e-14.
   - **충족**.

2. **Cohen's d ≥ 0.1**: ✓
   - per-artifact: d ∈ [+0.290, +1.053], 모두 d ≥ 0.29.
   - pooled: d = +0.640.
   - **충족** (모두 보수적 임계 +0.1 의 약 3x 이상).

3. **NetGain median Δ ≥ +3% on artifact-rich input**: ✗
   - bone_stretch: +0.0% (충족 0).
   - foot_floating: +0.6% (충족 ratio 20%).
   - global_jitter: +1.3% (충족 ratio 43%).
   - pooled: +0.000998 (per-pair). 절대값 small.
   - **미충족** — 모든 artifact 에서 +3% 미달.

#### §3 인용

- Per-artifact table → [§3-1](#3-1-per-artifact-netgain-변화-sequence---single_step).
- Pooled statistics → [§3-2](#3-2-pooled-across-artifacts).
- Per-sample gap distribution → [§3-3](#3-3-per-sample-gap-distribution-step-1-finding-2026-05-19b).
- Mathematical invariant → [§3-4](#3-4-mathematical-invariant-수학적-lower-bound).

#### 판정 해석

- **Direction**: closed-loop 가 single-step 보다 **strictly** 우세 (n_loss=0 across all 90 pairs, p < 1e-13 pooled, Cohen's d 가 medium-large).
- **Magnitude**: 통계적 우세는 robust 하나, **effect 의 절대 magnitude 가 +3% 미달**. 사전 등록 임계 (+3%) 의 의도는 "실용적으로 의미 있는 개선" 측정. 본 결과의 +0.6~1.3% 는 noise level 보다는 큼 (CI 가 0 을 포함하지 않음) 이나 임계 미달.
- **본 결과는 oracle level 측정** (각 candidate 의 best 선택). 실제 routing system (rule-based / learned) 가 oracle gap 의 일부만 closing 한다면 system-level magnitude 는 더 작을 가능성 — RQ1 의 fixed-post-processing baseline 측정 필요.

**최종 판정 표현**:
> H-2026-204 RQ2 의 direction-only criterion (Wilcoxon + Cohen's d) 은 strongly supports. magnitude criterion (+3% median Δ) 은 모든 artifact 에서 미달. **partial supports** — 사전 등록 임계의 일부만 충족.

#### Threshold 미달의 해석 (HARKing 차단, [eval-compare SKILL §8](../../.claude/skills/eval-compare/SKILL.md))

본 결과로 +3% threshold 를 사후 수정 (relax) 하지 않는다. 임계는 사전 등록 (2026-05-15) 그대로 유지하고, 결과는 partial supports 로 보고. 임계 수정이 필요하면 새 가설 draft + 사용자 승인 게이트.

#### 재해석 (2026-05-19 사용자 directive)

**가설 본문은 변경하지 않는다**. 본 절은 partial supports 결과의 **도메인 해석 framing** 만 추가한다 (HARKing 차단 — 사전 등록된 measurable threshold 와 기각 조건은 그대로).

사용자 directive (2026-05-19) 의 framing:

> closed-loop 는 단일 artifact synthetic correction 에서 **큰 NetGain 향상 장치라기보다, rollback / STOP / side-effect 감지를 위한 안정성 장치** 에 가깝다. 큰 이득은 **multi-artifact case** 또는 **G2 natural artifact** 에서 다시 검증해야 한다.

이 framing 은 본 §4 의 정량 결과와 일관:
- **direction 충족 (Wilcoxon p<1e-13, Cohen's d 0.6-1.0) → 안정성 차원의 가치 입증**: subset inclusion 보장 + 0 loss → closed-loop 가 single-step 보다 절대로 나쁘지 않다 (no-harm semantics). 이는 "rollback / STOP / side-effect 감지" 의 운영 가치에 부합.
- **magnitude 부분 미달 (+0.0~1.3% < +3% threshold) → 단일 artifact synthetic 상황에서는 closed-loop 의 추가 NetGain 이 small**: 사용자 framing 의 "큰 이득은 다른 setting" 과 일관.

**후속 검증 우선순위** (사용자 directive 박제):

1. **multi-artifact case** — 본 측정은 sample 마다 단일 artifact 만 inject. 실제 generator output 은 여러 artifact 가 동시 존재 (foot floating + jitter 동시 등). multi-artifact 에서는 첫 step 의 correction 이 다른 artifact 에 side effect 를 주고 그것을 다음 step 이 보정 → closed-loop 의 magnitude 가 더 클 것으로 기대.
2. **G2 natural artifact 분포** — synthetic injection 의 controlled artifact 와 generator 의 자연 artifact 는 distribution shape 가 다름. 특히 MotionGPT 의 token boundary artifact 등은 single-step correction 으로 fully 해결 안 될 가능성.
3. **System-level 측정** — oracle gap closing 비율 (rule-based / learned routing 이 oracle 의 몇 % 를 close 하는지). 본 측정은 oracle level 의 idealized 비교.

본 framing 의 박제 위치: 본 §4 (가설 평가) 의 재해석 절 + [reports/2026-05-19d.md](../../reports/2026-05-19d.md) (framing change 보존).

1. **Synthetic injection only** — 자연 artifact 분포 (G2 generator output) 미측정. H-2026-204 active scope 의 일부만 cover.
