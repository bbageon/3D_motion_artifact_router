# AR-081 — Strength-Q v1 결과: 사전등록 기준 **지지** (u* 정책 > 고정 u=1.0)

- 사전등록: [spec](../../.claude/docs/dashboard-task-specs/AR-081-strength-q-v1.md) (13차원 직관 이름 state·additive 구조·판정 기준 — 결과 보기 전 고정) · Raw: [result](../snapshots/strength_q_result_ar081_v1.json) · [dataset](../snapshots/strength_q_dataset_ar081_v1.csv) (2,699 motions × u 5, meta [json](../snapshots/strength_q_dataset_ar081_v1.json)) · 코드: [dataset](../../tools/strength_q_dataset_ar081.py) / [train](../../tools/strength_q_train_ar081.py)

## 2. 사전등록 판정: **"지지"** — 결정 계층 시리즈 최초

세 번의 이분법 gate(AR-078 benefit·richer / AR-079 harm-averse)가 전부 미달했던 자리에서, **강도 축(u)을 추가하자 사전 기준을 통과**했습니다. 이유는 구조적입니다:

1. **행동 공간이 문제에 맞음**: apply/STOP 이분법은 "애매하면 포기"만 가능했지만, u 축은 "애매하면 약하게"가 가능 — harm 을 낮추면서 improvement 를 버리지 않음.
2. **라벨이 연속**: 이분류(benefit@δ) 대신 실현 ΔMM 을 직접 회귀 — δ 경계의 정보 손실 없음.
3. **정책이 결과를 직접 최적화**: 점수 threshold 가 아니라 u-grid 위에서 기대 효용 argmax.

## 3. Shortcut 검사 — generator ID 암기가 아님

**no-gen 정책(10차원)도 단독으로 기준 통과** (+0.049 [+0.016, +0.084], harm −0.239). generator ID 를 빼도 상태(stepping_speed·shortfall·접지 신뢰도·intent)가 결정을 지탱 — **state-conditioned 가 실질**. gen 포함판은 improvement 소폭↑, no-gen 판은 harm 소폭↓ (0.086 vs 0.118).

## 4. 부속 결과

- **λ trade-off 지형** (calibration): λ=4 로 올리면 harm **1.4%** 까지 감소 (improvement 0.107) — no-harm 최우선 배포용 보수 모드가 이 축에 존재. λ*=0.5 는 사전 규칙(고정 u=1.0 이하 harm 중 improvement 최대)의 선택.
- **Markov 축약 검정**: (reward 보존) 유도 변수(root_speed_actual·path_length) 재투입 시 holdout RMSE 0.544→0.561 — **개선 없음** (포함 feature 의 함수이므로 정상; 제거 정당). (행동 보존) augmented 모델과의 argmax 불일치 36% — 인접 u 간 Q 표면이 평평한 구간의 모델 분산으로 해석 (실현 성능 차이는 위와 같이 없음; caveat 로 기록).

## Claim Boundary

**허용**: "one-shot root 보정에서 13차원 pre-action state 의 Q(s,u) 정책이 고정 최대 강도 대비 holdout improvement 를 유의 개선하고 harmful rate 를 1/3 이하로 낮췄다 (MM proxy, δ 조건부). generator ID 없이도 성립 (state-conditioned)."
**금지**: **"정책이 작동한다" (지각 검증 전 — spec §4)** / 지각·품질 개선 주장 (MM proxy) / closed-loop 성능 / RL-2 구계열(3/5-level·NetGain) 수치와 혼합 (§6-15) / δ 무관 확정.
