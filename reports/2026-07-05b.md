## Design Direction

Current `FootLockTool` changes only foot height:

```text
new_y = current_y + factor * (ground_y - current_y)
```

The new design should use coordinate contact segments:

```text
contact_t =
  foot_y - ground_y <= 0.05m
  and |vertical_velocity| <= 0.035m/frame
```

Then lock only eligible contact segments, not all frames:

```text
target_foot_xyz = (anchor_x, ground_y, anchor_z)
new_foot_xyz = current_foot_xyz + u * (target_foot_xyz - current_foot_xyz)
```

## Claim Boundary

Forbidden: this design proves foot skating is solved or replaces human/perceptual validation.

## Design Freeze (AR-060 execution, 2026-07-05)

Frozen implementation spec written: [.claude/docs/design/coordinate_footskate_cleanup_tool_frozen_spec.md](../.claude/docs/design/coordinate_footskate_cleanup_tool_frozen_spec.md).

Pinned against the REAL interfaces (not invented):

- `apply()` signature = unchanged base `CorrectionTool` (§3-2 preserved); frame_range re-read as the tool's *allowed window* while contact segments are detected internally.
- Coord-space precondition: operates on `motion_trajectory` (world) only — X/Z anchor is meaningless in `motion_local` (PELVIS=origin). `coord_space != "trajectory"` → `ValueError` (silent misuse block). This is the decisive difference from Y-only lock, which was ~coord-agnostic.
- v2 contact/skate constants match AR-058-3f/g (0.05 / 0.035 / 0.025). Segment validity requires `skate_frac >= 0.2` so clean contacts are NOT touched; ambiguous segments are reported, not forced.
- Anchor = **median X/Z** over contact frames (noise-robust default); anchor_y = `estimate_ground` (10th pct, coords_protocol) or `metadata.ground_y`.
- Leg-chain propagation foot/ankle/knee/hip = 1.0/0.5/0.2/0.1 on the full 3-vector delta — flagged as **engineering heuristic (NOT IK)**; BoneLengthCV guard watches for pose artifacts.
- `u ∈ [0,1]`, u_grid {0.25,0.5,0.75,1.0}, `action_space_type=bounded_continuous_u`; no learned-optimum claim.
- Guard metrics + Category tags pinned: foot_skate_world(B, primary↓), float_mag(B), artifact_total(**C**), BoneLengthCV(B), FID(**A**, equal-N). Comparison protocol = {none / Y-only FootLock / coordinate u_grid / oracle-u ceiling} per generator, paired Wilcoxon n≥20 snapshot≥2.
