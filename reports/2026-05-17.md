### Known issue — Length 제어 불가능

- prompt `"a person walks forward"` + `--n-frames 40` 요청 → 4 frames 생성.
- prompt `"a person jumps and then walks forward for a long time"` + `--n-frames 120` → 동일하게 4 frames.
- 원인: [`mGPT/models/mgpt.py:65~71`](../external_assets/MotionGPT/mGPT/models/mgpt.py) 의 `forward(batch, task='t2m')` 가 `batch['length']` 를 capture 만 하고 `lm.generate_direct(texts, do_sample=True)` 에 위임. T5 가 자체적으로 motion token 개수를 결정.
- 대응: 본 wrapper 는 metadata 의 `length_generated` 로 실제 길이 기록. 짧은 출력 방지하려면 `demos/t2m.txt` 의 60+ 단어급 상세 prompt 권장.
- AGENTS.md §2-1 "MotionGPT 의 known issue" 절에 명시 완료.
