## 요약

본 프로젝트의 framing 을 **독립 프로젝트** 로 보정한다. AGENTS.md §1 초기 표현 "**독립 후속 프로젝트**" 는 모순적이었고, 이를 근거로 G3 (이전 저장소의 LoRA-fine-tuned Gemma 4 자산) 가 본 프로젝트의 generator tier 인 것처럼 기재된 misregistration 이 다수 발견됐다. 본 일지의 결정 사항:

1. **Framing 보정**: 본 저장소는 motion refinement framework (ArtifactRouter) 의 **독립 프로젝트**. 이전 저장소 [`3D-Motion-Trajectory-prediction`](../../3D-Motion-Trajectory-prediction/) 의 LLM-based motion generation 실험 (이전 저장소 가설 H-2026-101·102) 의 **후속 연구가 아니다**. 이전 저장소에서 import 하는 것은 public dataset (HumanML3D) + 시각화 utility 수준 자산에 한정.
2. **가설 misregistration 정정**: H-2026-200·201·202 의 `track_scope: [G1, G2, G3]` 는 G3 inadvertent inclusion. 본 정정은 trial 0 / 결과 보기 전 misregistration 정정이므로 HARKing ([AGENTS.md §6-4](../AGENTS.md)) 비해당. supersede 새 H-id 발행: [H-2026-204](../evals/hypotheses/H-2026-204.md), [H-2026-205](../evals/hypotheses/H-2026-205.md), [H-2026-206](../evals/hypotheses/H-2026-206.md).
3. **Active generator scope**: G1 (diffusion-based: MDM/MLD) + G2 (**공식 MotionGPT** — <https://github.com/OpenMotionLab/MotionGPT> — 별도 설치). G3 (이전 저장소 자산) 는 본 프로젝트 scope 외, 코드는 vestigial reference 로만 보존.
4. **이전 저장소 의존 제거 (마이그레이션 계획)**: 현재 `external_assets/` 의 junction 들 (`HumanML3D`, `processed_noaug`) 을 본 저장소 내부 복사본으로 마이그레이션 예정. 사이즈 확인 + 사용자 승인 후 진행.

본 결정은 사용자 directive 와 사용자 승인 게이트 통과 (2026-05-15) 로 진행됐다.

## Design decision narrative

### 발견 과정

오늘 진행 중 사용자가 다음 두 가지를 명확히 했다:

1. **"이전 연구를 이용하여 후속연구를 한다가 아니라는점을 확실히 알아줬으면 좋겠어"** — 본 저장소는 이전 저장소의 후속 연구가 아니다. 이전 저장소의 자산 일부 (특히 MotionGPT 와 관련된 것) 를 재활용할 뿐이다.
2. **"공식 MotionGPT 를 처음부터 설치"** — 이전 저장소에 MotionGPT 자산이 있는지 검색했으나 결과 없음. MotionGPT 는 공식 OpenMotionLab repo 에서 별도 clone + checkpoint 다운로드.

이 framing 은 AGENTS.md §1 의 원본 표현 "**본 저장소는 이전 저장소의 sanity check 결과 위에 시작한 독립 후속 프로젝트**" 와 충돌한다. 그 표현은 "독립" 과 "후속 프로젝트" 가 동시에 들어가 있어서 모순적이고, "sanity check 결과 위에 시작" 이 후속 연구처럼 들리게 한다. 이 표현이 G3 (이전 저장소의 Gemma 4 LoRA 자산) 가 본 프로젝트의 generator tier 인 것처럼 기재된 misregistration 의 원천이었다.

본 일지 작성 직전 ca77992 commit 에서 "G3 기법 미증명 → active scope 제외 (workaround)" 라는 (일부 잘못된) framing 으로 supersede 를 진행한 적이 있고, 사용자의 framing 보정 후 ca77992 를 hard reset 으로 되돌리고 새 framing 으로 재작성한 것이 본 일지의 commit 이다.
