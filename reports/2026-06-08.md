## 1. 명세

## 2. 발견한 핵심 결함 (protocol 이 잡아낸 것)

1. **좌표 관례 불일치** (재빌드 전): MotionGPT=world(root_max 3.93) / MDM·MoMask=local(0). 같은 자로 foot skate·trajectory 비교 불가.
2. **길이 비제어**: MotionGPT 는 자체 length estimator 로 길이 변동(40~196, seed별 상이) → GT 기반 target 강제 불가. MDM/MoMask 는 target 정확 준수.

## 3. 교정 내용

- **이중 표현 통일** ([docker/{mdm,momask,motiongpt}/service.py](../docker/)): 3 서비스가 `motion_trajectory`(root 보존) + `motion_local`(파생) 둘 다 반환. `motion`=local 표준화(이전 MotionGPT=world 였음). docker 재빌드(service.py 막판 COPY 레이어라 빠름) + 재시작 + 검증: 3개 모두 dual=True, trajectory_root>0·local_root=0·정합 match=True, ground_y≈0.01m.
- **교정 prompt bank** ([tools/build_protocol_prompt_bank.py](../tools/build_protocol_prompt_bank.py)): test split · full-motion(0.0/0.0) · mirror dedup(non-M) · GT 존재 · 문장 dedup · GT길이[40,200) · target=min(4⌊L/4⌋,196).
- **ground 기준** ([tools/coords_protocol.py](../tools/coords_protocol.py)): min-Y 금지 → lower-foot-height 10th percentile.
- **length 규약 (사용자 결정 반영)**: common-min 으로 truncate 시 의미 손실 우려 → **semantic floor**. ratio=common_min/target ≥ **0.8** 인 prompt 만 채택(≤20% truncation). MotionGPT 는 native length(강제 불가), paired 비교는 per-prompt common_length 로 truncate.
