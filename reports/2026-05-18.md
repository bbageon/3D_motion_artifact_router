명세 §9.3.1 의 metric 정의를 그대로 구현:

| 파일 | 메트릭 | 출력 (EvaluatorReport) |
|---|---|---|
| [evaluators/foot_floating_evaluator.py](../evaluators/foot_floating_evaluator.py) | `FootFloating = mean_t I(contact_foot(t)) * I(p_foot_y(t) - ground_y > tau_float)` | left/right foot 별 score, 권장 tool: `foot_lock_tool` |
| [evaluators/bone_length_evaluator.py](../evaluators/bone_length_evaluator.py) | `BoneVar = mean_{t,b} |length_b(t) - length_b_ref| / length_b_ref` (reference = frame-wise median) | T2M kinematic chain 5 종 별 score, 권장 tool: `bone_projection_tool` |
| [evaluators/velocity_jitter_evaluator.py](../evaluators/velocity_jitter_evaluator.py) | `VelocityJitter = mean_{t,j} ||a_j(t)||` (acceleration L2 norm 평균) | global + body part (legs/arms/spine_head) 별 score, 권장 tool: `velocity_smoothing_tool` |

각 evaluator 는 [`evaluators/base.py`](../evaluators/base.py) 의 `Evaluator` 인터페이스를 구현하고 `EvaluatorReport` (agent / error_type / body_part / frames / score / severity / recommendation / metadata) 를 반환.

### Synthetic injection 도구 ([tools/synthetic_injection.py](../tools/synthetic_injection.py))

명세 §9.3 Protocol A (synthetic artifact injection) 의 prototype. 3 종 함수:

- `inject_foot_floating(motion, lift_height, frame_range, seed)` — foot 을 위로 들어올림.
- `inject_bone_stretch(motion, chain_label, stretch_factor, seed)` — 지정 chain 의 bone 들을 scaling.
- `inject_jitter(motion, noise_std, seed)` — gaussian noise 추가.

모두 입력 motion 을 변형하지 않고 새 array 반환 (immutability).
