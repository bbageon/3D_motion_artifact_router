## 2. 파악한 부분 — 주요 결과

### 2-1. Step 1 (Stage 0 보강) — H-205 사전 임계 정식 충족

| 사전 등록 임계 | v1 (n=27) | **v2 (n=42)** |
|---|---|---|
| 1. NetGain median Δ ≥ +5% (vs B5) | Pooled +7.7% | **+6.3%** ✓ |
| 2. p < 0.05 | 1.17e-04 | **2.78e-05** ✓ |
| 3. Cohen's d ≥ 0.3 | +0.55 | **+0.43** ✓ |
| 4. Oracle gap closure ≥ 30% | foot/jitter 100% | foot ~85%, jitter ~100% ✓ |
| 5. Decision agreement ≥ 50% | 88.9% | **84.4-85.6%** ✓ |
| **trial ≥ 30** | **27 (미달)** | **42 (충족)** ✓ |
| **n_seeds ≥ 3** | **1 (미달)** | **3 (model variance < 1.5%)** ✓ |

→ **H-205 Stage 0 single-artifact supports 의 caveat 완전 해소**.

### 2-2. Step 2 (ablation) — 학습 신호 isolation

| Ablation mode | tool_acc | strength_acc | NetGain median (bone/foot/jitter) |
|---|---|---|---|
| **none (baseline)** | 100% | 84.4% | +0.187 / +0.306 / +0.433 |
| **score_only** (artifact_kind 제거) | **100%** | 85.6% | +0.187 / +0.306 / +0.433 |
| **rule_tool_learned_strength** | 100% (rule) | 84.4% | +0.187 / +0.306 / +0.433 |

**결정적**: 3 mode 모두 NetGain 동일 → **학습 가치 = 100% strength prediction**. Tool 학습 무가치 (artifact_kind/scores 로 trivially 결정).

### 2-3. Step 3 (multi-artifact synthetic) — single-step ceiling 노출

| Baseline | NetGain median (foot+jitter target) |
|---|---|
| B1 (no refinement) | 0.000 |
| **B2 (fixed smoothing)** | **+0.180** |
| B5 (rule-based) | -0.058 ⚠ |
| B6 single (supervised) | +0.068 |

**Paired tests**:
- B5 vs B2: d=**-6.30** (huge negative) — B5 single-step 의 multi-artifact 한계.
- B6 vs B2: d=**-1.72** (large negative) — B6 single-step 도 B2 능가 못 함.
- B6 vs B5: d=+1.39 (B6 가 B5 보다는 우월).

→ **사용자 framing "multi-artifact 큰 이득" 은 single-step decision 으로는 검증 안 됨** — closed-loop refinement 필요.

### 2-4. Step 3.5 (B6 closed-loop multi-artifact) — 사용자 framing 정밀 검증

| Setting | B6 vs B2 |
|---|---|
| Single-artifact synthetic (Step 1) | **B6 > B2** (d=+1.07, supports) |
| Multi-artifact single-step (Step 3) | **B6 < B2** (d=-1.72, contradicts) |
| **Multi-artifact closed-loop** (Step 3.5) | **B6 cl ≈ B2** (d=-0.002, tie) ← catch-up only |

Step 3.5 paired test:
- **B6 cl vs B5**: d=**+1.79** (huge) — closed-loop + learned 결합 supports.
- **B6 cl vs B6 single**: d=**+0.95** (large) — H-2026-204 RQ2 multi-artifact 측면 supports.
- B6 cl vs B2: d=-0.002 (tie) — catch-up only, **B2 능가 못 함**.

**Bug 진단 + fix 박제** (HARKing 차단):
- v1 default `target_evaluators=[foot, bone, jitter]` → multi recipe 에 BoneLength 도 후보. 4 step 모두 BoneProjectionTool 잘못 선택.
- v2 fix: `target_evaluators=[foot, jitter]` 명시 → NetGain -0.034 → **+0.185**.

### 2-5. Step 4 (contextual bandit, full evaluator state) — single-step learning ceiling 확정

**사용자 directive 의 정확한 검증**: "BoneLengthEvaluator 까지 포함한 full state 에서 sequential policy 가 가능한가?"

| Comparison (multi-artifact, n=30 intersection) | Δ median | p_gt | Cohen's d |
|---|---|---|---|
| **B7 bandit vs B5** | +0.233 | 9.3e-10 | **+3.16** (huge) |
| B7 vs B6 cl | +0.083 | 0.42 | +0.07 (tie) |
| B7 vs B2 | +0.000 | 0.93 | -0.25 (slight neg) |

**결정적 finding**: **B7 ≈ B6 cl ≈ B2** — single-step learning 의 ceiling = fixed smoothing.
- Training data 의 best single action 분포: **VS/medium 90%** (54/60). 즉 multi-artifact 의 single-step best ≈ B2 동작.
- bandit_chose_stop=0/30 — STOP 학습 부재 (single-step Q 의 본질적 한계).
- → **multi-step value learning (trajectory-level RL) 필수**.

- 핵심 dependency: scikit-learn 1.7.2 (Step 1 에서 설치), numpy, scipy, pytorch (synthetic only, GPU 미사용).

### 명령어 (재현 가능)

```bash
# Step 1: Stage 0 표본 보강 + n_seeds=3

    --task-id oracle_single_step_v3 --split-id calibration_v2 \
    --netgain-preset calibrated_protocol_a_v1 ...

    --oracle-prefix oracle_single_step_v2 oracle_single_step_v3 \

    --training-data evals/snapshots/oracle_training_data_v2.json \
    --train-ratio 0.5 --model-random-state $mrs \
    --task-id baseline_b6_supervised_v2_seed$mrs ...

# Step 2: ablation
for mode in score_only rule_tool_learned_strength; do
  python -m tools.baseline_supervised_run --ablation-mode $mode ...

# Step 3: multi-artifact synthetic
for bt in b1_no_refinement b2_fixed_smoothing b5_rule_based b6_supervised; do

    --training-data evals/snapshots/bandit_training_data_v1.json \
    --train-ratio 0.5 --model-random-state 1 ...
```

## 5. 실패한 시도 (negative results) — AGENTS.md §3-13 의무

본 일자의 정직한 negative findings (HARKing 차단 + multi-step RL motivation 확립의 근거):

### 5-1. Step 3 — single-step B6 의 multi-artifact 한계
- single-artifact synthetic 에서 B6 > B2 (Step 1) 였으나 multi-artifact 에서 **B6 < B2** (d=-1.72).
- Spillover effect: B6 single-step 이 한 artifact 처리 시 다른 artifact 가 악화.

### 5-2. Step 3.5 v1 bug — target_evaluators default issue
- SupervisedSelectorOrchestrator default `target_evaluators=[foot, bone, jitter]` 가 multi-artifact recipe (foot+jitter) 에 BoneLength 도 포함.
- jitter spillover 로 BoneLength score 가 max → BoneProjectionTool 잘못 선택 4 step.
- NetGain median -0.034 (negative).
- **Fix**: `target_evaluators=[foot, jitter]` 명시 → +0.185.

### 5-3. Step 3.5 v2 의 catch-up only — closed-loop 만으로 B2 능가 불가
- B6 cl 가 B6 single 극복 (d=+0.95) + B5 압도 (d=+1.79).
- **단 B2 의 catch-all 효과 catch up 만** (d=-0.002, tie).

### 5-4. Step 4 — single-step bandit 의 ceiling
- B7 ≈ B6 cl ≈ B2 (all single-step learning ≈ fixed smoothing).
- bandit_chose_stop=0/30 — STOP 학습 부재.
- → trajectory-level value learning (multi-step RL) 필수.
