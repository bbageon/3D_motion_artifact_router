## 2. 파악한 부분 — 주요 결과

### 2-1. Step 5-A — B5 의 robust mechanism

**Per-tool effectiveness (B5 의 selected)**:

| Tool/strength | n | NetGain_med | foot_red | bone_red |
|---|---|---|---|---|
| **BP/small** | **19** | -0.001 | 0 | **+0.0043** ← B5 majority |
| BP/medium | 1 | -0.009 | 0 | +0.0032 |
| FL/large | 4 | +0.020 | +0.116 | 0 |
| FL/small | 6 | +0.004 | +0.029 | 0 |

**Per-tool effectiveness (B6_cl first step)**:

| Tool/strength | n | NetGain_med | foot_red | bone_red |
|---|---|---|---|---|
| **BP/large** | **18** | -0.006 | 0 | **0** ⚠ |
| **FL/medium** | **6** | **+0.046** | **+0.197** | +0.0003 ← G2 best! |
| FL/large | 3 | -0.004 | +0.033 | -0.013 |
| NONE | 3 | 0 | 0 | 0 |

**Mechanism isolation**:
- **B5 majority = BP/small** (19/30) — bone reduction +0.0043, fidelity loss 작음, NetGain ~0.
- **B6 majority = BP/large** (18/30) — bone reduction **0** (large strength 가 BP 의 chain projection 범위 벗어남) + fidelity loss 큼.
- **G2 의 실제 best = FL/medium** (6 trial, NetGain +0.046, foot_red +0.197) — 어느 baseline 도 majority 로 선택 못 함.
- **B5 vs B6_cl same tool 27/30** — tool 자체는 비슷한 mechanism (severity/score 기반), **strength 차이가 결정**.

### 2-2. Step 5-A — Distribution shift 정확한 정량

| | Synthetic (Step 1 oracle, n=180) | **G2 (Step 5-B oracle, n=30)** |
|---|---|---|
| **Strength** distribution | large 137 (76%) + medium 40 + small 3 | **small 25 (83%) + medium 5 + large 0** |
| **Tool** distribution | foot 60 + bone 60 + jitter 60 (artifact balanced) | BP 17 + FL 11 + VS 2 (G2 의 BoneLength dominant) |

→ **distribution shift mechanism**: synthetic 의 inject 가 high severity (lift_height=0.08, stretch=1.30) → strength=large best. G2 의 자연 artifact 는 low severity → strength=small best. **synthetic-learned policy 가 G2 에 over-modification**.

### 2-3. Step 5-B — Small-calibration 회복 명확

**G2 oracle distribution (n=30, 30 G2 motion × 9 actions)**:
- BP/small 16, BP/medium 1, FL/small 7, FL/medium 4, VS/small 2.
- strength=small 25 (83%) ← synthetic 의 large 76% 와 정반대.

**Calibrated retrain (G2 train 15, eval 15)**:

| | Zero-shot (synthetic) | **Calibrated (G2)** |
|---|---|---|
| NetGain median | -0.005 | **-0.002** |
| NetGain mean | -0.029 | **-0.003** |
| Strengths | **large 12 + medium 3** | **small 12 + medium 3** ← distribution shift fix |

**Paired test (zero-shot vs calibrated, n=15)**:

| Metric | Value |
|---|---|
| Δ median (cal - zs) | +0.00245 |
| Δ mean | +0.02583 |
| strict_advantage_calibrated | **11/15 (73%)** |
| **Wilcoxon p (greater)** | **0.0421** ✓ |
| Cohen's d | +0.209 (small) |

**판정**: H-2026-206 sub-supports — p<0.05 + 73% strict advantage ✓, 단 Cohen's d small (+0.21).

## 3. 실험 메타

### 환경
- conda env: `motion3d`, scikit-learn 1.7.2.

### 명령어 (재현)

```bash
# Step 5-A: decision trace 분석
python -m tools.analyze_g2_decision_trace \
    --raw-records-dir evals/raw \
    --output evals/snapshots/g2_decision_trace_analysis_v1.json

# Step 5-B: G2 oracle training data
python -m tools.build_g2_oracle_training_data \
    --g2-batch-dir external_assets/g2_generated_v1 \
    --output evals/snapshots/g2_oracle_training_data_v1.json

# Step 5-B: G2 small-calibration B6 (zero-shot vs calibrated)
python -m tools.baseline_b6_g2_calibrated_run \
    --g2-training-data evals/snapshots/g2_oracle_training_data_v1.json \
    --synthetic-training-data evals/snapshots/oracle_training_data_v2.json \
    --seed 42 --train-ratio 0.5 --model-random-state 1 \
    --task-id baseline_b6_g2_calibrated_v1 \
    --raw-output-dir evals/raw \
    --output evals/snapshots/baseline_b6_g2_calibrated_v1.json

# Paired test
python tools/_paired_test_g2_calibration.py \
    evals/snapshots/baseline_b6_g2_calibrated_v1.json
```

- G2 oracle measurement: deterministic (G2 motion 의 inject seed 가 G2 batch 시점에 고정, 본 단계 inject 없음).
- train/eval split seed: 42 (G2 30 → 15 + 15).
- model random_state: 1.

## 5. 실패한 시도 (negative results) — AGENTS.md §3-13 의무

### 5-1. B6 의 BP/large (G2 first step) 가 bone reduction 0
- **표면**: BoneProjectionTool 적용 (synthetic best label).
- **실제**: G2 의 자연 bone variation 이 BP 의 chain projection 범위 벗어남 + large strength 가 over-modification → bone reduction 0, fidelity loss 큼.
- → synthetic-learned strength 의 G2 distribution shift 정량 증거.

### 5-2. G2 의 ideal FL/medium 이 어느 baseline 도 majority 선택 못 함
- B5: severity small → FL/small 6 (majority FL 의 일부).
- B6 zero-shot: synthetic large → FL/large 3.
- **G2 oracle: FL/medium 4** — 단 어느 prediction policy 도 majority 로 채택 못 함.
- → **best action 의 distribution mismatch** — synthetic policy 도 B5 rule 도 G2 의 ideal 매핑 부재.

### 5-3. Small-calibration 의 small effect size (+0.21)
- p<0.05 + 73% strict 의 sub-supports 단 Cohen's d +0.21 (small).
- n=15 의 표본 한계.
- absolute NetGain 여전히 음수 (-0.002).
- → small-calibration mechanism 명확 단 magnitude small. 더 큰 G2 training data 또는 multi-step RL 의 motivation.
