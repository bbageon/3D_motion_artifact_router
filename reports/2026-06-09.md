### Part A 정량 audit ([snapshot](../evals/snapshots/motiongpt_length_audit_v1.json), [tool](../tools/motiongpt_length_audit.py), read-only)

- **극단 조기종료(≤8 frame): 1개** — `011743` seed20506610 "turning body from side to side" target 196 → actual **4**.
- **동일 prompt 길이 변동**(확률적 길이 직접 증거): 011743=[4,188,188] spread 184; 006281=[16,192,196]; 005676=[44,148,196] 등 15 prompt spread≥50.

### 원인 확정 (코드)

- [mgpt.py:67·71](../external_assets/MotionGPT/mGPT/models/mgpt.py): `lengths_ref=batch["length"]` 읽지만 `generate_direct(texts, do_sample=True)` 에 **미전달**.
- [mgpt_lm.py:229·268](../external_assets/MotionGPT/mGPT/archs/mgpt_lm.py): `generate_direct(max_length=256, do_sample=True)` → `max_new_tokens=256`+sampling → token 수·EOS **확률적**. VAE downsampling=4 → token 1개 조기 EOS = 4-frame.
- 4-frame = target 196, actual 4 (4<196 → **truncation 아님 = upstream generation**).
- **length-conditioned 경로 존재**: [mgpt_lm.py:279](../external_assets/MotionGPT/mGPT/archs/mgpt_lm.py) `generate_conditional(..., lengths=...)` — 단 현재 t2m forward 는 미사용.

### protocol 결정 (D)

- **native** = 현재 direct output = primary (length-failure prevalence 근거). pool 미변경.
- **length-conditioned** = `generate_conditional` 검증 시 별도 protocol/version (Part C 후속, service 수정 필요).
- **sensitivity** = cross-gen(AR-051)에서 극단 짧은 sample 포함/제외 분리 보고. 제외만 primary claim 금지.

### Part C length-conditioned 검증 (negative result, §3-13)

motiongpt service 에 `with_len` 모드 추가([generate_conditional](../external_assets/MotionGPT/mGPT/archs/mgpt_lm.py) — "Generate motion with N frames: caption" instruction) → 재빌드 → audit prompt 20개 × 3 seed × {direct, conditioned} 비교 ([snapshot](../evals/snapshots/motiongpt_length_conditioned_compare_v1.json), [tool](../tools/motiongpt_length_conditioned_compare.py)):

| metric | direct | conditioned |
|---|---|---|
| exact_match | 16.7% | **1.7%** (개선 안 됨, 오히려↓) |
| ratio 0.8~1.25 | 68.3% | 53.3% |
| degenerate ≤8frame | 0% | 0% |
| runtime | 0.48s | 0.40s |

- **length-conditioning(instruction)은 길이 제어를 개선하지 못함** — conditioning 이 soft(텍스트 지시)이고 decode 는 동일 do_sample(확률적)이라 stochastic 길이가 지배. → **easy fix 없음**.
- **4-frame 은 seed-specific 희귀 이벤트 확인**: 011743 이 새 seed 3개에서 direct=[188,188,188](4-frame 미재현). audit 의 1/900 4-frame = 확률적 tail.
- → **protocol 확정**: length-conditioned 로 대체 불가 → **native(direct) primary + cross-gen 에서 sensitivity(짧은 sample 포함/제외) 분리 보고**가 유일한 정직한 길.
