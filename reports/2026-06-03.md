### 해석

1. **AR-040 전제는 성립**: g2_stress 와 synthetic_diag 에 사전 정의 issue 가 실제로 존재한다.
2. **g2_stress 는 실제로 artifact-rich**: g2_natural 대비 artifact_total 이 약 4.1배.
3. **단 clean_noharm 은 "artifact-free" 가 아님**: HumanML3D clean 에서도 FootFloating proxy 26%, VelocityJitter proxy 8% 가 잡힘. 따라서 clean_noharm 은 "GT라서 완전 깨끗함" 이 아니라 **보정으로 더 망치면 안 되는 reference/no-harm split** 으로 표현해야 함.
4. **BoneLengthCV 는 G2 전반에서 강한 signal**: G2 full/stress/natural 모두 BoneLengthCVEvaluator > clean p99 가 100%. 이는 generator skeleton consistency issue 또는 evaluator-threshold domain gap 가능성을 함께 의미한다.

## 12. AR-029 — Standard Physical Metric on real g2_stress (FID 가 가린 효과 재측정)

**동기 (사용자 directive 2026-06-03)**: "흠집 전용 자(physical metric)로 real g2_stress 를 다시 재서, FID 가 가렸던 도구 효과가 실제로 있는지 확인". 선행 [generator failure-mode survey](../docs/generator_failure_mode_survey.md): FID(Category A, distributional)는 per-frame local foot artifact 에 둔감 → 표준 physical metric(Category B)으로 재평가.

### 산출물

### 데이터 (§3-17 real-distribution)
real MotionGPT 출력 (corruption 아님). closed-loop 보정 모션은 이미 cache(`closed_loop_final_motions_v1/`) → original/noop 대비 paired Δ (음수=개선, lower better).

### 핵심 결과 (g2_stress n=65, original means: foot_skate=0.0039 / accel_mean=0.0115 / float_mag=0.0317)

| metric | M0(safe) | heuristic | oracle | 방향 |
|---|---|---|---|---|
| **accel_mean** (smoothness, **ground-indep**) | d=-0.16 imp42% | d=-0.24 imp63% | d=-0.45 imp63% | **개선 (유의)** |
| accel_p95 | d=-0.14 imp29% | d=-0.24 imp58% | d=-0.39 imp49% | 개선 |
| **float_mag** (planted foot height) | d=-0.49 imp26% | d=-0.67 imp43% | d=-0.70 imp55% | 개선 (적용 subset) |
| **foot_skate** (GMD/EDGE 표준) | d=+0.40 imp2% | d=+0.43 imp2% | d=+0.66 imp3% Δ+13% | **악화** |

모든 셀 Wilcoxon p<0.05 (n_effective = 비-STOP subset). g2_natural(n=99) 동일 패턴(accel 개선, foot_skate flat~악화) — no-harm 측 catastrophic harm 없음.

### 해석 (정직)
- **FID 가 가린 효과는 부분적으로 실재**: acceleration(smoothness)는 **ground-independent 하게 유의 개선** — FID 가 못 본 유일한 깨끗한 축. 단 **효과 크기 작음**(d -0.16~-0.45, 절대값 tiny) — MotionGPT 가 이미 smooth.
- **단일 방향 깨끗한 개선 아님 — trade-off**: float↓ 이지만 표준 **foot_skate 는 오히려 악화** (planted foot 의 잔여 수평이동이 skate 로 등록 + ground 추정 민감). foot_skate original 0.0039 = VQ generator 라 **headroom 자체가 없음**.
- **공격적 정책(heuristic/oracle)은 FID 까지 악화**([standard_metric_closed_loop_v1](../evals/snapshots/standard_metric_closed_loop_v1.json): heuristic ΔFID +0.040). 즉 physical 일부 개선 ↔ FID 악화 동시 → 안전한 free win 아님.
- **survey 결론 재확인**: MotionGPT(token/VQ)는 physical headroom 도 작다. diffusion(MDM, AR-022)에서 foot_skate 가 실제로 높을 때 깨끗한 win 기대.

### §3-25 GATE_RELATIONSHIP
foot_skate/float 는 FootLockTool target 과 상관(독립 free-lunch 아님). claim = "표준 metric(Category B)으로도 smoothness 개선 + FID 보존(M0)/악화(공격적) 동시 확인", NOT "최적화 무관 독립 개선". gate_recheck=true (closed-loop gate-ON 생성). policy_contribution baseline = original/noop.

## 13. AR-046 — MotionGPT 시사점 문서화 + 대표(representative) 재집계

**동기 (사용자 directive)**: ① MotionGPT 에 대한 본 연구 시사점 정리 → docs 폴더화. ② stress 단독(enriched) 대신 **전체 비율(prevalence-weighted) 대표 결과 + no-harm** 을 헤드라인으로, stress/natural 은 진단 보조.

### 산출물
- [docs/dataset/](../docs/dataset/README.md) — G2=MotionGPT pool 데이터셋 카드. [docs/findings/](../docs/findings/README.md) — 시사점 F0(평가단위)~F6 + 주장 경계.
- [tools/representative_aggregate_g2.py](../tools/representative_aggregate_g2.py) + [snapshot](../evals/snapshots/representative_aggregate_g2_v1.json) — prevalence-weighted 대표 집계. AGENTS.md §8 index 갱신.

### 방법론 (§3-22)
stress 는 artifact proxy(=router 단서)로 고른 enriched subset → 단독 보고 = selection bias. 대표 주장은 full 분포 (HumanML3D protocol Guo CVPR2022; MDM ICLR2023; MoMask CVPR2024). band 실제 비율: stress **20.7%** / low-artifact 79.3% (naive 65:99 concat 은 stress 39.6% = ~2배 과대표집).

### 대표 헤드라인 (prevalence-weighted)
- **FID/R-Prec (Category A) = NEUTRAL** (M0 ΔFID +0.004, oracle +0.006; R@1 ±0.001) — 개선도 손상도 없음.
- **no-harm 확정**: clean GT Δ = 정확히 0.00000 (전 정책·전 metric).
- artifact proxy(Category C) -11.5%/-24.6%/-29.2% — 단 **stress 소수 집중·내부 proxy**(stress-only -18~-40% 에서 희석).
- physical(B): accel/float 소폭↓ vs foot_skate↑ (trade-off, magnitude tiny; bootstrap CI 0 제외=유의이나 작음).

### 정직한 결론
MotionGPT 에서 주장 가능 = **"safe no-harm refinement (standard quality NEUTRAL 보존) + artifact proxy 의 minority 감소"**. **"real quality 향상" 주장 불가.** stress-only(AR-029/016)는 mechanism 진단 한정.

### Intent-Reconciliation (§3-23)
- **Intent**: 시사점 정리 + 대표 재집계(stress 단독 탈피). **Acceptance**: full 분포 가중 + no-harm + stress 진단 격하(성능 입증 아님).
- **Actual**: 대표 FID NEUTRAL + clean Δ=0 + proxy minority 감소. stress/natural 진단표 유지.
- **Verdict**: `aligned`. earlier stress-centric 인용을 대표로 교정(정직성↑). scope_creep/side-effect 없음.
