## 4. 파악한 부분 — Step 6 의 핵심 findings

1. **Real gate + Q policy = 0% violation across ALL 4 holdouts** — physical gate 가 safety 를 실제 보장. baseline 중 random (4.2%) / heuristic (39.6%) 는 synthetic 에서 violation (per-step gate 의 한계 영역). **Q 정책은 gate 와 결합 시 완전 안전**.

2. **M0+gate > random+gate / heuristic+gate (사용자 핵심 질문 답: YES, 단 조건부)**:
   - **synthetic_diag**: M0 +0.0775 (0% viol) >> random +0.0546 (4.2% viol) >> heuristic −0.0239 (39.6% viol). **decisive**.
   - **clean_noharm**: M0 0% rejection vs heuristic 100% / random 57.9%. **효율 압도**.
   - **g2_natural**: M0 −0.0002 (least harm) > random −0.0187 > heuristic −0.0057.
   - **g2_stress**: heuristic +0.0139 ≈ M1 +0.0141 ≥ M0 +0.0084 (NetGain 만으로는 heuristic 경쟁적), 단 heuristic rejection 18.9% (M0 4.3%) + dense oracle +0.0249 headroom 존재. **g2_stress 가 M0 의 약점 — 추가 개선 여지**.

3. **M1 G2-only specialization 의 closed-loop 확인** (Step 5 offline 의 closed-loop 검증):
   - clean: act 35% + **rejection 34.8%** (unsafe 후보 반복 제안, gate 가 막음).
   - synthetic: **100% over_STOP** (G2 밖 regime 전혀 못 다룸).
   - → offline 의 pick_unsafe 56% 가 closed-loop 에선 gate 로 0% violation 되지만, **rejection/over_STOP 비용** 으로 드러남.

4. **dense_oracle_step1 = 명확한 upper bound**: 모든 holdout 에서 best NetGain (synthetic +0.1663, g2_stress +0.0249), 0% violation, lowest cand_evals (single step). **learned policy 와 oracle 사이 gap 이 여전히 존재** — Stage 3 continuous argmax / 추가 학습 의 headroom.

5. **candidate_evals / rejection_rate 가 정책 품질의 숨은 축**: NetGain + violation 만 보면 M0 ≈ M2 이지만, M0 의 rejection rate 가 일관되게 낮음 (clean 0%, g2_natural 0.4%, g2_stress 4.3%). **"적은 검증 비용으로 안전한 후보 제안" 기준에서 M0 우월** (사용자 criterion).

## 5. 정직 보고 (AGENTS.md §3-13) — M0 의 약점

- **g2_stress 에서 M0 NetGain (+0.0084) 이 heuristic (+0.0139) / M1 (+0.0141) 보다 낮음**. 단 heuristic 은 rejection 18.9% (비효율) + g2_stress 의 dense oracle +0.0249 가 보여주듯 M0 가 회수 못 한 headroom 존재. M0 가 "안전하고 효율적이나 stress 에서 보수적" — Stage 3 / 추가 학습 의 target.
- closed-loop 가 single-step dense 가 아닌 max_depth 3 인데 dense_oracle 은 step-1 only (단일 step ceiling). sequence oracle 과의 gap 은 별도 측정 필요 (현 oracle 은 lower-bound ceiling).
