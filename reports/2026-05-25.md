## 2. 파악한 부분 — 주요 결과

### 2-1. 사용자 directive 의 분기점 정답 — **"B2 를 넘는 sequence 가 실제 존재"**

**Paired test (n=30 common, NetGain_A, B2 multi-compatible)**:

| Metric | Sequence Oracle (K=5) | B2 multi | Δ (oracle - B2) |
|---|---|---|---|
| NetGain median | **+0.314** | +0.180 | **+0.144** |
| NetGain mean | **+0.303** | +0.179 | +0.124 |
| n_strict_oracle / n_tie / n_loss | **30 / 0 / 0** (clean separation) | | |
| **Wilcoxon p (one-sided, oracle > B2)** | **9.3e-10** | | |
| **Cohen's d (paired)** | **+1.71** (very large) | | |
| Bootstrap CI median | [+0.100, +0.168] | | (no zero crossing) |
| Bootstrap CI mean | [+0.097, +0.148] | | (no zero crossing) |

→ **30/30 sample 모두 oracle strict > B2**. action space 의 천장 아님. **Multi-step RL 진입 정당한 motivation 확립**.

### 2-2. Search mechanism 의 정량 발견

- **best_length=5 dominant (16/30 = 53%)** — K=5 가 binding constraint. multi-artifact 의 본격 회복 에는 평균 5 step 필요.
- **first_action=FootLockTool 29/30 (97%)** — foot floating 이 multi-artifact 의 first priority.
- **Search complexity**: per sample ~2600 paths explored (range 1500-4500). Pruning (Score 비감소 + same-pair strength decay) 가 worst case 10^5 = 100K → ~수천 paths 로 축소.
- Same-pair strength decay 가 sequence 의 핵심: 큰 strength 로 시작 → 점차 감소 (예: FL/large → FL/medium → FL/small) → 정밀 회복. single-step 은 본 ramping 자체가 불가.

### 2-3. B7 framing 교정 박제

사용자 directive (2026-05-24) 인용:
> "B7 = contextual bandit baseline. B7 을 'RL' 이라고 단독 표현하지 않기. 'single-step RL-style policy' 또는 'contextual-bandit baseline' 으로 표기. 진짜 RL 은 trajectory-level value learning 이후부터 사용."

본 일지 (2026-05-25) 부터 정정 적용:
- **B7 = contextual-bandit baseline = single-step RL-style policy**. NOT trajectory-level RL.
- 본 프로젝트의 보고서 (2026-05-20, 2026-05-21 등) 는 이미 "B7 bandit" / "contextual bandit" 표기 일관 (grep 확인) — 본 directive 와 충돌 없음.
- "Multi-step RL" (부록 K-10, L-8 의 future work) = **Trajectory-level value learning** (Q-learning, value iteration, sequence-oracle imitation). 본 부록 M 의 +0.124 mean gap 이 정식 motivation.

## 12. RL-1 진단 보강 (사용자 6-step roadmap Step 1, Order 3.6 진단)

> 본 절은 사용자 directive (2026-05-25 6-step roadmap): "RL-1 진단 보강 — 바로 Q-learning 으로 가지 말고 먼저 원인을 분리. (a) 데이터 부족, (b) state feature 부족, (c) RandomForest 모델 한계, (d) imitation 방식 자체 한계." controlled diagnostic 의 4 origin 정량 verdict.

### 12-1. 진행사항

| 항목 | 이유 |
|---|---|
| RL-1 진단 도구 ([`tools/rl1_diagnose.py`](../tools/rl1_diagnose.py)) 작성 | 4 진단 (multi-seed + state ablation + confusion matrix + failure trace) 통합. 정적 분석. |
| Multi-seed (model_random_state ∈ {1..5}) | underperformance 의 random variance 진단. |
| State ablation (full16 / no_delta / no_prev / scores_only) | 사용자 16-dim state design 의 sub-feature 효과 정량. |
| Confusion matrix on eval (n=72 pairs) | action 학습의 strong/weak class 식별. |
| Failure trace (5 rollback samples) | step-by-step (true vs pred + top3 proba) — fail mechanism 정밀. |
| 부록 R append + 일지 §12 (본 절) | controlled diagnostic finding 박제. |

### 12-2. 파악한 부분 — 4 진단 결과

**(B) Multi-seed**: eval_acc mean **0.669 ± 0.012** (range [0.653, 0.681]). variance 매우 작음. → **model seed randomness 가 underperformance 의 주요 원인 아님**.

**(C) State ablation**:

| Ablation | dim | eval_acc | Δ vs full16 |
|---|---|---|---|
| full16 | 16 | 0.667 | — |
| no_delta | 13 | **0.681** | **+1.4%p (better!)** |
| no_prev | 8 | 0.625 | **-4.2%p** |
| scores_only | 3 | 0.389 | -27.8%p |

→ **prev tool/strength 중요**, **score delta 무용** (counter-intuitive). state design 의 큰 여지 작음.

**(D) Confusion matrix (eval n=72)**:
- **STOP recall 96% (23/24)** — abstain 학습 매우 강함.
- Bo/sma → STOP misclassified 4/12 (over-conservative).
- Ve/med → Bo/sma misclassified 4/8 (cross-tool).
- Adjacent strength confusion: FL/sma ↔ FL/med ↔ FL/lar.

**(E) Failure trace (5 fail trials)**:
- **Step 0 strength adjacent** (002652, 013152) — RF probabilities close (0.45 vs 0.37).
- **Over-confident wrong** (005366) — VS/large @ prob 0.94 (true VS/medium).
- **Cross-tool confusion** (012644) — FL/small → VS/large.
- **Error propagation** (M000758) — step 1 발산 (FL/small @ 0.89, true VS/large), 이후 5/6 MISS.

### 12-3. 결정적 finding — 4 origin verdict

| Origin | Verdict | 정량 evidence |
|---|---|---|
| **(a) 데이터 부족** | **부분 yes** | n_train=160 매우 작음, mid-step state redundancy 부족. → synthetic oracle n=60 expansion 가치 있음. |
| **(b) State feature 부족** | **mixed (no)** | prev tool/strength 중요, score delta 사실상 무용. state design 큰 여지 작음. |
| **(c) RandomForest 한계** | **yes (dominant)** | train_acc 1.0 vs eval_acc 0.67 (33%p gap), over-confident wrong, adjacent strength boundary 학습 약함. |
| **(d) Imitation 방식 한계** | **부분 yes** | M000758 의 5/6 MISS = error propagation. distribution shift (training oracle state vs closed-loop visited state). |

→ **종합**: (c) 모델 한계 + (a) 데이터 부족이 dominant. (d) distribution shift 는 1/5 sample 의 dramatic case — **RL-2 trajectory-level value learning 의 정식 motivation 강화**.

### 12-4. 학술적 의미 — 사용자 framing 정확한 박제

- **RL-1 의 진정한 성과**: G2 abstain learning (STOP recall 96%) — H-2026-203 supports robust evidence.
- **RL-1 의 한계**: synthetic multi-step decay sequence 학습 — RF over-confident wrong + imitation distribution shift.
- **다음 step 의 정식 motivation**: data 보강 (RF model 의 generalization 가능성 진단) + alternative model 시도 + RL-2 trajectory-level (distribution shift 의 정식 해소).

### 12-5. 실패한 시도 / negative result

- 사용자 16-dim state design 의 sub-component 분석 결과 **score delta 가 사실상 redundant** (드롭 시 오히려 향상). negative finding 박제. 다음 RL-1/RL-2 design 에서 state 13-dim 으로 축소 또는 score delta 의 alternative encoding (예: derivative 의 sign 만) 검토.

## 13. RL-1 v2 Data Sufficiency 검증 (Order 3.6-A 완료, 같은 일자 후속)

> 본 절은 부록 R 의 (a) data 부족 가설 정량 검증. Synthetic oracle expansion (n=30 → n=60) + RL-1 재학습 + paired test + 진단 v2. controlled diagnostic finding.

### 13-1. 진행사항

| 항목 | 이유 |
|---|---|
| Synthetic oracle n=60 background ([`oracle_sequence_multi_v2_n60.json`](../evals/snapshots/oracle_sequence_multi_v2_n60.json)) | (a) data 가설 정량 검증. 부록 R 의 background task 완료. |
| RL-1 training data v2 build (375 pairs, +62% vs v1) | sample 다양성 증가 (synthetic 의 first_action FL 97% → 72%, VS 27% 도입). |
| RL-1 baseline v2 재학습 + closed-loop eval | v1 (eval n=9 synthetic + 15 G2) → v2 (n=18 synthetic + 15 G2). |
| B2 multi v2 (n=60) 재실행 | paired cohort 일관화. v1 eval (n=9) 와 v2 eval (n=18) 의 sample mismatch 해소. |
| RL-1 진단 v2 (multi-seed + ablation + confusion + trace) | 4 origin verdict 정밀화. |
| 부록 S append + 일지 본 절 update | 정량 evidence 박제. |

### 13-2. 파악한 부분 — v1 vs v2 핵심 결과

**Synthetic** (data 보강의 효과 정량):
- NetGain median: v1 **+0.020** → v2 **+0.168** (+0.148 — **큰 향상**).
- Rollback ratio: 56% → 39% (-17%p, sequence 학습 안정성 향상).
- vs B2 Cohen's d: -0.26 → -0.10 (sub-B2 마진 축소, 단 여전히 sub).
- **Oracle gap closure: -40% → -15.6% (+24.4%p — data 가설 정량 supports)**.

**G2** (abstain 유지):
- selector_stop: 100% → 93% (small variation, eval set 다름).
- vs B2 Cohen's d: +1.48 → +1.02 (still large positive).
- length=0 (STOP-best): 14/15.

**Model capacity (v1 vs v2)**:
- train_acc: 1.000 → 1.000 (RF over-fit 유지).
- eval_acc (multi-seed mean): 0.669 → 0.627 (-4.2%p, eval 다양성 증가).
- **train-eval gap: 33%p → 37%p** — **RF generalization 한계 더 명확**.

### 13-3. 결정적 finding — 4 origin verdict 정밀화

| Origin | v1 verdict | v2 verdict |
|---|---|---|
| **(a) 데이터 부족** | partial yes | **partial yes 정량 confirmed** — gap closure +24%p. **단 ceiling 도달**, 여전히 sub-B2. |
| (b) State feature 부족 | mixed (no) | **mixed (no) confirmed** — v2 ablation: full16/no_delta/no_prev 모두 ~0.62 (변동 작음). |
| **(c) RF 한계** | YES (dominant) | **YES (DOMINANT) — 더 명확** — data 보강해도 train-eval gap 37%p 유지. |
| (d) Imitation distribution shift | partial yes | partial yes (rollback 56% → 39% 향상, 여전히 큼). |

→ **결론**: data 보강이 큰 효과 (gap closure +24%p), 단 **RF model 한계 가 다음 bottleneck** (37%p gap 유지). **Alternative model 시도 또는 RL-2 진입의 정식 motivation 강화**.

### 13-4. 학술적 의미 (사용자 framing)

- **(a) data 가설 정량 confirmed but limited**: data 보강 단독으로 oracle ceiling 도달 불가.
- **(c) RF 한계 가 dominant**: RF 의 over-fitting + adjacent strength boundary 학습 한계.
- → **다음 step 의 정식 motivation**: Alternative model (LR / GBM / MLP) — RF 한계 가설의 직접 검증.

### 13-5. 실패한 시도 / negative result

- v1 의 ablation 에서 score delta drop 시 +1.4%p 향상 발견 — v2 에서는 0%p (no improvement). **small-sample noise 였을 가능성** 박제. state design 13d vs 16d 차이 없음.
