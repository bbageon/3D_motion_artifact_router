# 연구일지 — 2026-05-19 (Priority 2 — Sequence Oracle)

> 본 일지는 사용자 권장 순서 2 단계 — sequence oracle (closed-loop fair upper bound) 구현 + 30 sample 측정 + single-step oracle 과의 비교. Priority 1 (NetGain weight calibration) 의 후속.

## 용어 풀이 (본 일지의 전문 용어)

- **Single-step oracle (1-단계 신탁)** — 한 sample 에 tool 을 **한 번만** 적용해 가장 좋은 결과를 고르는 baseline. Priority 1 의 oracle_single_step_v2 가 본 측정.
- **Sequence oracle (시퀀스 신탁)** — 한 sample 에 tool 을 **여러 번 순차 적용** 한 시퀀스 중 best 를 고르는 baseline. 본 일지의 산출물.
- **DFS** (Depth-First Search, 깊이 우선 탐색) — 트리의 한 가지를 끝까지 따라간 후 되돌아오는 탐색 방식.
- **Exhaustive search (완전 열거)** — 모든 경우의 수를 빠짐없이 시도.
- **Score 비감소 가지치기 (pruning)** — 매 step 의 TotalArtifactScore (모든 evaluator 의 raw score 합) 가 직전보다 증가하면 본 분기를 잘라낸다 ([AGENTS.md §3-4](../AGENTS.md)).
- **Fair upper bound (공정한 상한선)** — closed-loop refinement (반복 보정 루프) 가 자기 운영 규칙을 지키며 도달 가능한 최대 성능. closed-loop 와 비교 가능한 baseline.
- **Calibrated_protocol_a_v1** — Priority 1 의 grid search 로 결정된 NetGain weight (α=5.0, β=0.0, γ=0.0). Protocol A (synthetic injection 의 MPJPE) 와의 순위 상관 (Spearman ρ) 최대화 결과.
- **Gap (격차)** — 두 baseline 의 NetGain median 차이. closed-loop 의 추가 가치 척도.
- **MPJPE** (Mean Per-Joint Position Error) — frame·joint 별 위치 오차의 L2 평균. 두 motion 의 거리 측정.

## 요약

`orchestrator/oracle_sequence.py` 에 sequence oracle (최대 depth=3 의 DFS exhaustive + Score 비감소 가지치기) 를 구현 + 30 sample 본격 측정 + single-step v2 와의 비교. **3 종 artifact 모두 gap < 0.005** — 본 calibrated weight + depth=3 + synthetic injection 조건에서 closed-loop 의 추가 가치가 micro-marginal. 다만 alpha grid extension 후 결과가 달라질 가능성을 noted-issue 로 기록.

## 파악한 부분

### Sequence vs Single-step 비교 결과 (30 samples, depth=3, calibrated_v1 weights)

| Artifact | Single-step NetGain median | Sequence NetGain median | **Gap** | Best sequence length 분포 |
|---|---|---|---|---|
| `bone_stretch_right_arm` | +0.1869 | +0.1869 | **+0.0000** | length 3: 28, length 2: 1, length 1: 1 |
| `foot_floating` | +0.4408 | +0.4429 | **+0.0020** | length 1: 8, length 2: 8, length 3: 14 |
| `global_jitter` | +0.4326 | +0.4361 | **+0.0035** | length 2: 5, length 3: 25 |

**의미**:

1. **모든 artifact 에서 gap ≤ 0.0035** — 본 조건 (calibrated_v1, depth=3, synthetic injection) 에서 closed-loop 의 single-step 대비 추가 가치가 매우 작음.
2. **`bone_stretch_right_arm` 의 gap=0.0000** 인데 best length=3 이 28/30 — 시퀀스가 길어도 NetGain 값이 single-step 과 같음. 즉 BoneProjectionTool 의 multi-step 반복이 ranking 에 영향 안 줌 (이미 1 step 으로 target metric 거의 0 도달, 추가 적용은 marginal).
3. **`global_jitter` 의 best length=3 가 25/30** — 반복 smoothing 이 jitter 감소에 누적 효과는 있지만 NetGain gap 으로 보면 작음.
4. **`foot_floating` 의 best length 분포 가장 다양** — sample 별로 1/2/3 step 이 best. motion-dependent.
5. **첫 tool 선택은 일관적** — bone_stretch → BoneProjection 30/30, foot_floating → FootLock 29/30 (1 sample 만 VelocitySmoothing), global_jitter → VelocitySmoothing 20/30 + FootLock 10/30.

### 탐색 효율

- 탐색된 candidate 수 (per sample × artifact): 평균 600-750, max 820 (= 1 + 9 + 81 + 729 leaf).
- Pruned (Score 비감소 위반) 분기: 평균 40-60 per sample. Score 비감소 의무가 의미 있게 작동 (전체 분기의 약 5-10%).

### [H-2026-204](../evals/hypotheses/H-2026-204.md) RQ2 검증 관점

본 결과는 **diagnostic** 수준의 비교이며 본격 supports/contradicts 판정의 근거가 아님. 의의:

- closed-loop refinement (반복 보정 루프) 가 single-step 대비 의미 있는 추가 가치 갖는지 의 **사전 신호**.
- 본 결과 만으로 H-204 의 RQ2 (closed-loop vs single-step) 를 contradicts 로 단정 금지 — 본격 evaluation 의 5단계 리포트 (trial ≥ 20 + paired test + effect size + α grid extension) 가 필요.

가능한 다음 검증:
- **α grid extension** (5 → {5, 10, 20, 50}) — α 가 더 클 때 multi-step 의 fidelity_loss 변화가 NetGain 에 더 큰 영향을 줄 가능성.
- **depth=5 까지 확장** — 현재 depth=3 으로 가지치기 후 ~750 candidate. depth=5 면 ~50k candidate. prune-search (best-first or A*) 도입 필요.
- **Stop 결정의 fairness 강화** — 현재 sequence oracle 의 candidate 에 length=0 부터 포함되므로 fair stop. 추가 검증으로 length-bounded subset 비교도 검토.

## 실패한 시도 (Negative Results)

- 본 단계의 직접적 실패 없음.
- **noted-issue (가설 평가 단계 이전에 확인 필요)**:
  - **α=5.0 grid boundary 미해결** — Priority 1 의 grid search 가 α=5 (grid 최대값) 에서 멈춤. 본 sequence vs single-step 의 gap=0.005 이 α=5 의 한계 때문일 가능성. 본격 평가 전 α grid extension ({5, 10, 20, 50}) 권장.
  - **depth=3 의 sequence 길이 한계** — closed-loop refinement loop 의 max_iterations 가 보통 5 이상이므로 depth=3 sequence oracle 은 부분 비교. depth=5 까지 확장하려면 prune-search 도입 필요.
  - **synthetic injection 의 단일 종류 corruption** — 실제 motion artifact 는 multi-artifact (foot_floating + jitter 동시 등). 본 단계는 single-artifact per sample 만 측정.
