### 2-2. 3-layer architecture 의 정식 규약 (사용자 directive 박제)

| Layer | 역할 | 파일 |
|---|---|---|
| **Global rule declaration** | 절대 규칙 의 한 줄 statement + cross-link + 위반 effect | `AGENTS.md` (slim, target <800 lines) |
| **Phase-specific rule** | sensor (02) / test (03) / evaluation (04) 의 phase 별 규칙 + 구체 절차 | `.claude/rules/phase/02-sensor.md`, `03-test.md`, `04-evaluation.md` |
| **Skill / Executable spec** | 구체 실행 절차 / 5-step / table / 예시 / format | `.claude/skills/<X>/SKILL.md` 또는 `docs/<topic>.md` |

본 architectural separation 의 의무 form (AGENTS.md §3-N) — 사용자 directive 의 직접 박제:

```
### 3-N. <Rule Name>

<사용자 directive 박제 + 1-3 문장 rule statement>

상세 spec (구체 절차 / table / 예시): [`.claude/skills/<X>/SKILL.md`](path) 또는
[`.claude/rules/phase/0X.md §X-Y`](path) 또는 [`docs/<topic>.md`](path).

**위반 시 effect**: <기존 rule cross-link> 동급/동질 의 silent invalidation 취급.
```

### 2-3. Intent-Reconciliation Loop 의 정식화 (§3-23 + SKILL)

**5-step loop** (사용자 directive 박제):
1. **Intent 식별** (사용자 directive verbatim / H-id / 외부 2020+ 논문 / 자가 메타 규칙).
2. **Acceptance criteria 식별** (정량 + 정성, 사전 정의 — HARKing 차단).
3. **Actual outcome 측정** (snapshot metric + 정성 관찰).
4. **5 verdict 분류**: `aligned` / `partial` / `misaligned` / `scope_creep` / `unintended_side_effect`.
5. **일지 박제 + (필요 시) 사용자 보고**.

`misaligned` / `scope_creep` / `unintended_side_effect` 는 **사용자 보고 의무** (commit 보류 또는 confirm 요청).
