### 2-3. 원인 확정

**transformers 5.8.1 의 T5ForConditionalGeneration 의 weight tying 처리가 MotionGPT 와 incompatible**:

- MotionGPT 의 ckpt 는 `shared.weight` 와 `lm_head.weight` 를 **서로 다른 값** 으로 저장 (학습 시 tied weight 가 untied 됐거나 의도적 untie).
- transformers 5.8.1 가 `config.tie_word_embeddings=True` 인 model 을 build 한 후 load_state_dict 호출 시:
  - 경고 메시지: `"The tied weights mapping and config for this model specifies to tie shared.weight to lm_head.weight, but both are present in the checkpoints with different values, so we will NOT tie them."` ← 인지는 하나
  - 실제 load 동작: `shared.weight` 자리에 `lm_head.weight` 값을 넣음 (구체적 mechanism 불명, 그러나 결과는 분명).
- LM 의 input embedding = `shared.weight` 가 broken → encoder 의 token embedding 이 의미 정보 없는 weight → encoder 가 prompt 무시 + decoder 가 random sample → 1 motion token (4 frame) collapse.

transformers 4.30.2 는 본 weight tying 처리 정상 → checkpoint 의 `shared.weight` 가 그대로 load → encoder 의 token embedding 정상 → prompt-dependent 동적 길이 생성.
