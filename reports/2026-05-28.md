### 2-3. **결정적 결론 — learned policy 에서는 3-level 우월**

**사용자 가 outline 한 분기 중 "3-level > 5-level" branch 확정**:

1. **5-level 은 oracle ceiling 이 높지만 (+0.246 vs +0.207) learned policy 가 못 따라감** (gap closure 54%).
2. **3-level 은 ceiling 이 낮지만 learned policy 가 훨씬 더 따라감** (gap closure 83%) → **절대 NetGain 더 높음** (+0.171 > +0.134).
3. **5-level strength grid 가 imitation bottleneck** — strength_match 27% (5-level) vs 62% (3-level), mean distance 1.04 vs 0.33.

→ **"5-level strength grid가 imitation bottleneck을 만든 것"** (사용자 directive 의 분기 해석) 의 정량 confirm.

## 3. 결정적 finding — Action Space 의 reframe

### 3-1. Oracle ceiling ≠ learned policy 의 정량 분리 (memory feedback-oracle-vs-learned 의무)

| 항목 | 5-level | 3-level |
|---|---|---|
| **oracle ceiling** (synthetic NetGain) | +0.246 (높음) | +0.207 (낮음) |
| **learned policy** (synthetic NetGain) | +0.134 | **+0.171 (높음)** |
| **gap** (learned/ceiling) | 54% | **83%** |

**핵심**: oracle 의 우월성 (5-level) 이 learned policy 의 우월성 으로 이어지지 않음. **action space 가 클수록 imitation 이 어려움** (5-level strength 의 fine-grained matching 27%).

### 3-2. RL-2 action space 결정 의 reframe (2026-05-26 의 Case A 정정)

2026-05-26 의 RL-2 action space 결정 (5-level, Case A) 은 **synthetic oracle 의 우월** 근거 — 단 본 비교 가 **learned policy 측면 에서는 3-level 이 우월** 임을 보임:

| 관점 | 우월 grid |
|---|---|
| **Oracle ceiling** (이론적 상한) | 5-level (synthetic Case A, 2026-05-26) |
| **Learned policy** (실제 imitation) | **3-level** (본 비교, closed-loop NetGain + gap closure) |

→ **사용자 directive 의 "5-level이 oracle에서는 좋았지만 learned policy에서는?" 질문 의 답: learned policy 에서는 3-level 이 더 좋음** (imitation bottleneck 회피).

## 4. 학술적 의미

- **Action space granularity 의 oracle-vs-learned trade-off** 의 정량 evidence — fine-grained action (5-level) 은 oracle headroom 을 늘리지만 imitation learning 의 sample complexity 증가 로 learned policy 성능 저하.
- 논문 문장: "While the 5-level strength grid yields a higher oracle ceiling, the learned imitation policy achieves higher closed-loop net gain with the 3-level grid (oracle gap closure 83% vs 54%), as fine-grained strength selection becomes an imitation bottleneck (strength match 62% vs 27%)."
- 본 finding 은 future constrained RL (Q-learning / value iteration) 가 5-level 의 ceiling 을 회수할 수 있는지 의 motivation — imitation 의 한계 를 RL exploration 으로 극복 가능성.

---

## 5. 실패한 시도 / negative result

- 5-level 의 oracle Case A advantage (2026-05-26) 가 learned policy 로 직접 transfer 안 됨 — oracle 평가 만으로 action space 결정 의 위험 (memory feedback-oracle-vs-learned 의 직접 사례).
- G2 의 3-level/5-level 차이 거의 없음 (둘 다 abstain-dominant, NetGain ~0) — G2 영역 에서는 action space granularity 무관.
