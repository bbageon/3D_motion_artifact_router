### 2-3. **결정적 결론 — learned policy 에서는 3-level 우월**

**사용자 가 outline 한 분기 중 "3-level > 5-level" branch 확정**:

1. **5-level 은 oracle ceiling 이 높지만 (+0.246 vs +0.207) learned policy 가 못 따라감** (gap closure 54%).
2. **3-level 은 ceiling 이 낮지만 learned policy 가 훨씬 더 따라감** (gap closure 83%) → **절대 NetGain 더 높음** (+0.171 > +0.134).
3. **5-level strength grid 가 imitation bottleneck** — strength_match 27% (5-level) vs 62% (3-level), mean distance 1.04 vs 0.33.

→ **"5-level strength grid가 imitation bottleneck을 만든 것"** (사용자 directive 의 분기 해석) 의 정량 confirm.

## 3. 결정적 finding — Action Space 의 reframe

### 3-1. Oracle ceiling ≠ learned policy 의 정량 분리 (memory feedback-oracle-vs-learned 의무)

| 항목 | 5-level | 3-level |
|---|---|---|
| **oracle ceiling** (synthetic NetGain) | +0.246 (높음) | +0.207 (낮음) |
| **learned policy** (synthetic NetGain) | +0.134 | **+0.171 (높음)** |
| **gap** (learned/ceiling) | 54% | **83%** |

**핵심**: oracle 의 우월성 (5-level) 이 learned policy 의 우월성 으로 이어지지 않음. **action space 가 클수록 imitation 이 어려움** (5-level strength 의 fine-grained matching 27%).

### 3-2. RL-2 action space 결정 의 reframe (2026-05-26 의 Case A 정정)

2026-05-26 의 RL-2 action space 결정 (5-level, Case A) 은 **synthetic oracle 의 우월** 근거 — 단 본 비교 가 **learned policy 측면 에서는 3-level 이 우월** 임을 보임:

| 관점 | 우월 grid |
|---|---|
| **Oracle ceiling** (이론적 상한) | 5-level (synthetic Case A, 2026-05-26) |
| **Learned policy** (실제 imitation) | **3-level** (본 비교, closed-loop NetGain + gap closure) |

→ **사용자 directive 의 "5-level이 oracle에서는 좋았지만 learned policy에서는?" 질문 의 답: learned policy 에서는 3-level 이 더 좋음** (imitation bottleneck 회피).

## 4. 학술적 의미

- **Action space granularity 의 oracle-vs-learned trade-off** 의 정량 evidence — fine-grained action (5-level) 은 oracle headroom 을 늘리지만 imitation learning 의 sample complexity 증가 로 learned policy 성능 저하.
- 논문 문장: "While the 5-level strength grid yields a higher oracle ceiling, the learned imitation policy achieves higher closed-loop net gain with the 3-level grid (oracle gap closure 83% vs 54%), as fine-grained strength selection becomes an imitation bottleneck (strength match 62% vs 27%)."
- 본 finding 은 future constrained RL (Q-learning / value iteration) 가 5-level 의 ceiling 을 회수할 수 있는지 의 motivation — imitation 의 한계 를 RL exploration 으로 극복 가능성.

## 5. 실패한 시도 / negative result

- 5-level 의 oracle Case A advantage (2026-05-26) 가 learned policy 로 직접 transfer 안 됨 — oracle 평가 만으로 action space 결정 의 위험 (memory feedback-oracle-vs-learned 의 직접 사례).
- G2 의 3-level/5-level 차이 거의 없음 (둘 다 abstain-dominant, NetGain ~0) — G2 영역 에서는 action space granularity 무관.

## 10. Step G-1 — Standard Metric FID + Diversity (Category A, 외부 공개 evidence)

### 10-1. 사용자 directive 박제

> "Step G는 3-level primary로 진행. FID / R-Precision / MM-Dist / Diversity / physical violation rate / perceptual sanity. 3-level learned / 5-level learned / safe oracle / B2-family 를 같이 비교."

### 10-2. Tool + 설정

[tools/standard_metric_fid.py](../tools/standard_metric_fid.py) (mgpt env) — HumanML3D official tm2t evaluator (movement_encoder + motion_encoder, `deps/t2m/t2m/text_mot_match/model/finest.tar`) + process_file (xyz → 263-dim) + Comp_v6 mean/std normalize.

- **Metric category**: A (standard, HumanML3D/Guo 2022 CVPR) — NetGain (Category C proxy) 과 독립.
- GT reference: HumanML3D clean new_joints n=300 (natural distribution).
- Methods: G2 test300 의 noop / B2-best / safe_oracle_3level / safe_oracle_5level.

### 10-3. 결과 — FID vs GT

| Method | n | **FID vs GT** | Diversity |
|---|---|---|---|
| GT_ref (HumanML3D clean) | 300 | (ref) | 9.229 |
| **noop (G2 original)** | 300 | **0.5748** | 9.507 |
| **B2-best (fixed smoothing)** | 300 | **0.7123 (+24%)** | 9.436 |
| safe_oracle_3level | 300 | 0.5751 (≈ noop) | 9.510 |
| safe_oracle_5level | 300 | 0.5752 (≈ noop) | 9.509 |

### 10-4. **결정적 결과 — 3-axis evidence 완성**

| Axis | B2 (NetGain-only) | safe oracle (gate-aware) |
|---|---|---|
| **NetGain (Category C proxy)** | +0.196 (높음) | +0.246 (oracle ceiling) |
| **Physical violation (Category B gate)** | **39%** | **0%** |
| **Standard FID (Category A)** | **0.712 (악화, +24%)** | **0.575 (≈ noop, 보존)** |

→ **B2 의 높은 proxy NetGain 은 physical consistency (39% bone violation) 뿐 아니라 distributional naturalness (FID +24%) 도 악화**. gate-aware orchestration 은 두 axis 모두 보존.

### 10-5. 정성 해석

1. **B2-best FID 0.712 > noop 0.575**: fixed smoothing 이 모든 motion 을 per-joint 독립 smoothing → bone 왜곡 (F-5 의 BoneLengthCV) → natural HumanML3D 분포 에서 멀어짐.
2. **safe oracle FID 0.575 ≈ noop 0.575**: G2 safe oracle 이 STOP-dominant (대부분 motion 보존) → FID 변화 거의 없음. **불필요한 correction 회피 가 naturalness 보존**.
3. **3-level vs 5-level oracle FID 동일** (0.5751 vs 0.5752): oracle 수준 에서 grid 의 FID 차이 없음 (둘 다 STOP-dominant G2).
4. **modest absolute 차이** (0.575 vs 0.712): G2 가 low/moderate severity 라 correction 의 FID 영향 작음 — 단 B2 의 over-correction 의 방향성 은 명확 (FID 악화).

### 10-6. 핵심 message (외부 공개, Category A 동반)

> "A fixed smoothing baseline (B2) achieves high proxy NetGain (+0.196) but degrades both physical consistency (39% bone-length violations) and distributional naturalness (FID 0.712 vs 0.575 for no-op). Gate-aware safe orchestration preserves both (0% violations, FID 0.575)."

본 결과 가 **safe orchestration thesis 의 외부 공개 grade evidence** (Category A FID + Category B gate + Category C NetGain 의 3-axis 일관).

### 10-7. 한계 (정직 박제)

1. **FID absolute 차이 modest** (G2 low/moderate severity). synthetic severe 의 FID 는 별도 측정 의무 (severe 에서 차이 클 예상).
2. **R-Precision / MM-Dist (text semantic) 미측정** — Step G-2 (text co-embedding) 의무. semantic preservation 의 직접 metric.
3. **safe oracle ≈ noop FID** 는 STOP-dominance 의 결과 — RL-2 learned policy 의 FID (correction 적용된) 는 별도 측정 가능.
4. perceptual validation (사람 평가) — perceptual pilot v2 framework 존재, 응답 수집 대기.

### 10-8. Intent-Reconciliation (AGENTS.md §3-23)

- **Intent**: 사용자 directive — Step G standard metric (FID 등) 으로 외부 공개 evidence 보강.

## 11. Step G-2 — R-Precision + MM-Dist (semantic preservation, Category A)

### 11-1. 사용자 directive 박제

> "G-2: R-Precision / MM-Dist 먼저. correction이 prompt semantics를 깨는가? (R-Precision) motion-text embedding distance가 악화되는가? (MM-Dist). safe oracle이 noop 수준으로 semantic preservation을 유지하는가?"

### 11-2. Tool + 설정

[tools/standard_metric_rprec.py](../tools/standard_metric_rprec.py) (mgpt env) — HumanML3D tm2t text_encoder + motion_encoder co-embedding. spacy en_core_web_sm tokenization (HumanML3D recipe: NOUN/VERB lemmatized). R-Precision (top-1/2/3 retrieval, 32-batch) + MM-Dist (matched motion-text distance).

- text 는 method 무관 동일 (caption per sample), motion 만 method 별 → **method 간 비교 valid** (tokenization absolute 차이 무관).

### 11-3. 결과 — R-Precision + MM-Dist (G2 test300)

| Method | R@1 | R@2 | R@3 | MM-Dist |
|---|---|---|---|---|

| safe_oracle_5level | 0.4247 (≈) | 0.6016 (≈) | 0.6814 | 3.9715 (≈) |

### 11-4. 결과 해석 — semantic preservation 의 4-metric 완결

| Standard metric (Category A) | noop | B2 | safe oracle | 방향 |
|---|---|---|---|---|
| **FID** (naturalness) | 0.575 | 0.712 | 0.575 | B2 악화 (+24%) |

**결정적 일관성**:
- **B2 가 모든 standard metric 에서 noop 보다 악화** (FID 명확 +24%, R-Precision/MM-Dist 일관 but modest).
- **safe oracle 이 모든 metric 에서 noop 보존** (≈ noop, semantic + naturalness 둘 다).
- → B2 의 high proxy NetGain 은 naturalness (FID) + semantics (R-Prec/MM-Dist) + physical safety (gate) **세 축 모두 악화**. safe orchestration 은 세 축 보존.

### 11-5. 한계 (정직 박제)

1. **G2 의 magnitude modest** — R-Precision/MM-Dist 차이 작음 (B2 R@1 -0.004, MM-Dist +0.032). G2 가 low/moderate severity + safe oracle STOP-dominant → 대부분 보존. **방향은 명확 (B2 악화), magnitude 는 synthetic severe (G-3) 에서 클 예상**.
2. **spacy tokenization absolute 값** — HumanML3D 원본 token 과 미세 차이 가능 (R@1 0.42 의 absolute 는 published 와 다를 수 있음). 단 method 간 비교 valid (동일 tokenization).
3. **가장 강한 standard evidence 는 FID (+24%)** — R-Precision/MM-Dist 는 direction confirm 의 보조.
