### 3-4. Q-disagreement summary (active learning hint)

| 카테고리 | 비율 |
|---|---|
| **unsafe-as-safe** (Q 가 unsafe 를 safe 로 잘못 봄) | **23.1%** (963/4160) |
| safe-as-unsafe (Q 가 safe 를 unsafe 로 봄) | 0.9% (39/4160) |
| total disagreement | 24.1% |

**대칭이 아닌 편향**: Q 의 false-safe (23.1%) >> false-unsafe (0.9%). 즉 Q 는 **optimistic bias** (safe 쪽으로 over-predict). B-0 의 calibration curve (predicted P_safe 0.55–0.85 영역 overconfidence) 와 mechanism 일관.

mined hard set 의 23.1% unsafe-as-safe = Stage B-0 의 일반 synthetic eval 7.4% (P_safe≥0.5) 의 약 3 배. **mining 이 정확히 bias 영역을 잡았다** — Stage 2 재학습 의 정합한 데이터.

## 4. 파악한 부분 (audit-driven mining 의 효과)

1. **mining 영역의 정확성**: 4,160 transition 중 84.6% hard, Q-disagreement 24.1% (일반 synthetic 의 ~3 배). audit 의 u=0.2 peak + VelSmooth tool 지시 가 정확.
2. **VelSmooth = high-utility-unsafe 의 primary source**: 1,115 high_util_gate_fail (FootLock 52 의 20 배+). Stage 2 재학습 시 VelSmooth × u=0.125-0.275 영역 의 P_safe label 보강 이 핵심.
3. **Q 의 편향이 비대칭 optimistic**: false-safe 23.1% vs false-unsafe 0.9%. Stage 2 의 loss 가중 (false-safe 에 더 높은 penalty) 또는 conservative threshold 가 의미. CQL/IQL 의 conservative 동기와 일관.
4. **u=0.10 boundary 의 "쉬운" 영역**: 거의 모두 hard 지만 Q 정확 (Q-uas 4). 작은 개입 = 명확히 unsafe-not-helpful, Q 가 잘 학습. 진짜 어려운 boundary 는 u=0.20-0.25 의 high-utility-unsafe 영역.

**사용자 spec 사이즈 와의 차이** (정직 보고):
- 사용자 spec: train 300 / calib 75 / stress_holdout 100 / natural_holdout 100 / reserve 25.
- 실제: train 338 / calib 71 / stress_holdout 65 / natural_holdout 99 / reserve 27.
- 사이즈 차이는 pool 의 band 분포 (stress=124, normal=353, clean_like=123) 와 "train 에도 stress 가 들어가야 한다"는 framing 의 trade-off. stress_holdout 65 < 100 은 pool 의 총 stress 가 124 라 50% 분배 시 도달 가능 최대치. **사이즈 < 의도 = stress in train 확보**.

## 15. 파악한 부분

1. **walking-overfit 위험 정량적으로 해소** — jump/run/turn/dance stress 모두 1→10+ (10 배 증가).
2. **train_g2_real 에 stress 37 motion 포함** — 사용자 framing "G2 real stress 가 RL 학습의 핵심" 충족 (v1 의 0 stress 문제 해결).
3. **HumanML3D test pool 의 group 분포 의 자연적 skew**: walking 1,017 available vs jump 263 / dance 140 / run 232. 자연 분포 가 walking 편향 — stratification 이 명시적으로 필요.
4. **'other' 15.7%** 는 keyword 분류기의 한계 (multi-verb / unusual prompts). 향후 NLP classifier 보강 가능 — Stage 2-G v3 후보.

## 16. Intent-Reconciliation (AGENTS.md §3-23)

- **Intent**: 사용자 옵션 A — G2 pool 600 + motion-group stratified prompt selection + group-wise stress profiling + group-balanced split with stress in train.

## 20. 파악한 부분 — 정직 보고 (사용자 framing 과의 divergence)

1. **M0 (Stage A diverse) 가 모든 4 holdout 에서 best 또는 tied-best**:
   - g2_stress: M0 pick_unsafe 9.2% (M1 15.4%, M2 13.8%).
   - g2_natural: M0 pick_unsafe **0%** (M1 3%, M2 4%).
   - **clean_noharm: M0 pick_unsafe 0% — perfect no-harm vs M1 56% catastrophic, M2 12%**.
   - synthetic_diag: M0 recovery 1.01 vs M1 0.00 (complete failure).

2. **M1 (G2-only) 의 catastrophic 모드** — 사용자 framing "G2 real 중심" 의 **specialization 위험 정량 확인**:
   - **clean_noharm pick_unsafe 56%**: G2-only training 이 "clean motion 에서 STOP" 학습을 잃어버림.
   - **synthetic_diag 100% over_STOP**: G2 만으로 synthetic regime 인식 불가, 항상 STOP.
   - calib R²=0.88 in-sample 강력 하지만 holdout R²=0.22 — **memorization without generalization**.

3. **M2 (G2 + synthetic aux) 가 부분 회복** — synthetic_diag 회복 (recovery 1.22), 단 clean_noharm 은 여전히 12% pick_unsafe (M0 의 0% 보다 나쁨).

4. **M3 isotonic post-cal 의 효과 미미** — PR-AUC 변화 거의 없음, 일부 holdout 에서는 oversteps 로 PR-AUC 하락 (g2_stress 0.632→0.529, g2_natural 0.719→0.631). Threshold tuning 보다 Loss / data 가 더 중요.

5. **honest framing divergence**: 사용자 가 "G2 real 가 중심" 으로 학습 데이터 구성을 지시했지만, **데이터 다양성 (Stage A 의 broad mix: clean+g2+synthetic+near_boundary) 이 training data 의 G2-specialization 보다 OOD generalization 에 우월**. CQL/IQL 의 "broad data support" 원리와 일관.
