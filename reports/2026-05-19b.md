# 연구일지 — 2026-05-19 (Step 1 — Sequence oracle tie-break 수정 + per-sample gap 분석)

> 본 일지는 사용자 직전 directive 의 Step 1 — sequence oracle 의 tie-break (동률 깨기) 점검·수정 + per-sample gap 의 정확한 통계 산출. 사용자 의문 "closed-loop refinement 가 항상 single-step 보다 낫다 — 본 주장의 근거가 약하다" 의 정량 응답.

## 용어 풀이 (본 일지 한정)

- **Tie-break (동률 깨기)** — 두 후보의 score 가 정확히 같을 때 무엇을 우선할지 정하는 규칙.
- **Per-sample gap (sample 별 격차)** — **같은 sample 의 같은 artifact** 에서 sequence oracle 의 best NetGain 에서 single-step oracle 의 best NetGain 을 뺀 값. sample 단위로 closed-loop 가 single-step 보다 얼마나 나았는지 측정.
- **Strict advantage (strict 우위)** — gap > 0, 즉 sequence 가 single-step 으로 도달 불가능한 NetGain 을 달성한 sample.
- **Closed-loop refinement** — motion 에 tool 을 반복 적용해가며 보정하는 알고리즘.

## 요약

사용자가 직전 일지의 "median gap=0" 결과의 신뢰성을 의심한 것이 정확. 두 가지 발견:

1. **Tie-break artifact 일부 확인**: bone_stretch 의 best length 분포가 v1 (tie-break 수정 전) 의 `{3: 28, 2: 1, 1: 1}` 에서 v1.1 (수정 후) 의 `{1: 8, 2: 6, 3: 16}` 으로 변함. 즉 동률에 더 짧은 시퀀스 우선하면 BoneProjectionTool 1 회 적용만으로 best 인 sample 이 8/30 발생.
2. **그러나 medians 비교의 정보 손실 더 큰 문제**: median NetGain 끼리 비교 (median of medians) 가 per-sample 분포의 신호를 가렸음. **per-sample gap 분석** 결과:
   - `bone_stretch`: 22/30 sample 에서 sequence 가 strict 우위 (gap > 0). 단 magnitude 매우 작음 (max +0.00008).
   - `foot_floating`: 22/30 strict 우위, max gap +0.020.
   - `global_jitter`: **30/30 strict 우위** — 모든 sample 에서 closed-loop 가 single-step 으로 도달 불가능한 NetGain 달성. max gap +0.031.

**결론**: "Closed-loop refinement 가 항상 single-step 보다 낫다" 는 **수학적으로 (gap ≥ 0 by 부분집합 포함)** 성립하며 **empirically 73-100% sample 에서 strict 우위**. 직전 일지의 "median gap=0" 은 measurement artifact (median of medians 의 정보 손실) 였음. 사용자 직관이 정확.

### Tie-break 수정 효과 (length 분포 변화)

| Artifact | v1 length 분포 (no tiebreak) | v1.1 length 분포 (tiebreak) |
|---|---|---|
| `bone_stretch_right_arm` | length 1: 1, 2: 1, **3: 28** | length **1: 8**, **2: 6**, 3: 16 |
| `foot_floating` | length 1: 8, 2: 8, 3: 14 | length 1: 8, 2: 8, 3: 14 (변동 없음) |
| `global_jitter` | length 2: 5, 3: 25 | length 2: 5, 3: 25 (변동 없음) |

bone_stretch 만 큰 변화 — `(FootLock, FootLock, BoneProjection)` 같은 prefix-padded sequence 가 `(BoneProjection)` 1 회와 정확히 같은 final motion (FL 이 bone 에 영향 0) 인 동률 케이스가 다수였음. v1.1 의 length 분포가 진실에 가까움.

foot_floating / global_jitter 는 변동 없음 — 이 두 artifact 는 sequence 가 길어질수록 NetGain 이 **strict 증가** 하므로 동률이 발생 안 함.

### Per-sample gap 분포 (정확한 RQ2 척도)

`oracle_sequence_vs_single_step_v1` snapshot 결과:

| Artifact | n | strict_advantage (gap > 0) | tie (gap = 0) | loss (gap < 0) | gap median | gap max |
|---|---|---|---|---|---|---|
| `bone_stretch_right_arm` | 30 | **22/30 (73%)** | 8/30 | 0 (수학적 보장) | +0.00000 | +0.00008 |
| `foot_floating` | 30 | **22/30 (73%)** | 8/30 | 0 | +0.00281 | +0.02007 |
| `global_jitter` | 30 | **30/30 (100%)** | 0/30 | 0 | +0.00580 | +0.03123 |

**핵심 해석**:

1. **`Sequence max NetGain ≥ Single-step max NetGain` 은 수학적으로 항상 성립** — sequence oracle 의 후보 set 이 single-step 의 superset (length=1 sequence 가 single-step 후보와 동일). 따라서 `loss` (gap < 0) 는 0 이어야 하며 실제 측정 결과도 0.
2. **Empirically (실측 기준): closed-loop 는 73-100% sample 에서 strict 우위**:
   - `global_jitter`: 30/30 (100%) — smoothing 의 누적 효과로 매번 도움.
   - `bone_stretch` / `foot_floating`: 22/30 (73%) — 8 sample 에서는 1-step 만으로 충분 (saturation).
3. **gap magnitude 는 작음** (median +0.000 ~ +0.006, max +0.000 ~ +0.031) — closed-loop 의 추가 가치 크지 않음.

### 사용자 직전 의문에 대한 답

> "Closed-loop refinement 가 항상 single-step 보다 낫다. 지금 해당 주장의 근거가 약하다."

**정확한 답**:
- 수학적으로 closed-loop oracle 은 single-step oracle 의 NetGain 을 절대 underperform 안 함 (gap ≥ 0). 본 의미에서 "항상 ≥".
- 실측 (synthetic injection 30 sample 기준): **73-100% sample 에서 strict 우위**, 7-27% 는 tie (= single-step 으로 충분).
- 직전 일지의 "median gap=0" 은 closed-loop 가 strict 우위가 아니라는 의미가 아니라 **median 비교의 정보 손실** 이었음. 실제로는 median 만 본 7-27% (= 단일-step 충분) 사례가 median 위치에 모여 보였음.
- magnitude 작은 점은 **별개의 문제** — calibrated_protocol_a_v1 weight (α=5.0) 의 grid boundary 미해결 (Priority 1 의 noted-issue) 이 영향 가능. Step 2 (α extension) 에서 검증.
