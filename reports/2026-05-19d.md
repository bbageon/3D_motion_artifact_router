## 2. 파악한 부분 — 사용자 framing 의 핵심

### 2-1. 사용자 directive (원문)

> closed-loop 는 단일 artifact synthetic correction 에서 큰 NetGain 향상 장치라기보다, **rollback / STOP / side-effect 감지를 위한 안정성 장치**에 가깝다. 큰 이득은 **multi-artifact case** 또는 **G2 natural artifact** 에서 다시 검증해야 한다.

### 2-2. 정량 결과와의 일관성

| Step 4 (5단계 리포트 §3) 의 측정값 | 안정성 장치 framing 과의 부합 |
|---|---|
| n_loss = 0 across all 90 pairs | subset inclusion 보장 → closed-loop 가 single-step 보다 **절대로 나쁘지 않다**. "no-harm semantics" — 안정성 가치. |
| paired Wilcoxon p<1e-13 (pooled) | direction (sequence ≥ single_step) 이 통계적으로 매우 robust → "rollback 보장" 차원의 신뢰성. |
| Cohen's d = +0.64 pooled (medium-large) | 효과 방향성은 명확. 단 magnitude 가 작아 "큰 이득이 아니다" 와 일관. |
| NetGain median Δ = +0.0~1.3% (per artifact), pooled +0.001 | 사전 등록 threshold (+3%) 미달. 단일 artifact synthetic 에서는 closed-loop 의 추가 가치 small. |

framing 은 **사후 합리화 (HARKing)** 가 아닌, partial supports 결과의 **도메인 해석** 이다:
- 가설 본문 (사전 정의·기각 조건·measurable threshold) 변경 없음 ([5단계 리포트 §4](../evals/reports/2026-05-19_h_2026_204_rq2.md#h-2026-204-rq2--closed-loop-refinement--single-step) 의 "HARKing 차단" 절).
- "rollback / STOP / side-effect 감지" 는 본 가설 본문에 명시적으로 적힌 표현은 아니나, **subset inclusion + score 비감소 pruning + STOP action** 으로 framework 가 이미 구현 (orchestrator/oracle_sequence.py 의 `score_increase_tolerance` + length-0 candidate 포함).
- 가설 평가 결과의 "운영적 가치" 차원 해석 — supports/contradicts 단정 외 부가 정보.
