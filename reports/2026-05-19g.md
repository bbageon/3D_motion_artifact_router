sample 0 OUT: shape=(1, 4, 22, 3), abs_sum=93.7402, non_zero=True

**두 prompt 결과가 byte-identical** (abs_sum 가 정확히 같음) — LM 이 prompt 무시하고 같은 token sequence 만 생성. 이는 매우 abnormal 한 deterministic collapse.

### 2-4. 새 원인 추정 (가장 유력)

**transformers 버전 호환성**:
- MotionGPT-base 학습 시점 transformers 버전 (추정 4.x, 2023 release) 과 mgpt-clean env 의 **transformers 5.8.1** (2025-2026 release) 의 `resize_token_embeddings` 구현이 다름.
- transformers 경고 ("new embeddings will be initialized from multivariate normal distribution") 가 매번 출력 — vocab 확장된 motion token (`<motion_id_0>` ~ `<motion_id_513>`) 의 embedding/lm_head 가 **random 초기화 후 checkpoint state_dict 로 덮어지지 못함** 의심.
- random embedding 으로 inference → LM 이 prompt-independent random token (대부분 EOS) sample → 1 motion token (4 frame) collapse + **다른 prompt 라도 같은 결과** (random init 가 deterministic seed=1234 로 같음).
