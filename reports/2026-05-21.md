### 2-4. 결정적 새 finding (synthetic ↔ G2)

| Setting | Ranking |
|---|---|
| Multi-artifact synthetic (Step 3.5/4) | **B2 ≈ B6 cl ≈ B7** (catch-all dominant) |
| **G2 natural** | **B5 ≈ B6 cl > B2**, **B7 < B2** (catch-all 깨짐, distribution shift) |

**핵심**:
1. **Synthetic 의 single-step ceiling 부분 재현** — B7 bandit 만 VS-only 그대로 transfer (98/98), 단 G2 에서 fail.
2. **B6 supervised 의 G2 정직한 부적합** — BoneLength dominant 보고 BP 선택, 단 G2 의 자연 bone variation 못 줄임.
3. **B5 rule-based 가 G2 에서 가장 robust** — severity-adaptive 가 distribution-agnostic.
4. **H-2026-206 (generator transfer) 정량 negative** — synthetic 학습 selector 의 G2 zero-shot transfer 부정.

## 5. 실패한 시도 (negative results) — AGENTS.md §3-13 의무

본 일자의 정직한 negative findings:

### 5-1. B7 bandit 의 G2 zero-shot transfer fail
- B7 가 synthetic 에서 학습된 VS-only policy 를 G2 에 그대로 적용 (VS 98/98).
- G2 에서 VS 가 자연 artifact (BoneLength 28 reports) 거의 못 줄임.
- NetGain median = -0.020 (모든 baseline 중 worst).
- **H-2026-206 generator transfer 의 정량 negative**.

### 5-2. B6 supervised 의 G2 정직한 부적합
- B6 의 학습 data 는 single-artifact label (foot→FL, bone→BP, jitter→VS).
- G2 의 BoneLength dominant state → primary=BoneLength → BP 선택.
- 단 BP 가 G2 의 자연 bone variation 거의 못 줄임 (bone reduction = 0).
- 학습 data distribution 과 G2 distribution 의 mismatch 명확.

### 5-3. 모든 baseline 의 absolute NetGain 음수
- G2 motion 자체가 reference 라 어떤 modification 도 fidelity_loss > 0.
- α=5.0 calibration 의 Protocol B transfer 시 magnitude 종속.
- target_delta 변화 (artifact reduction) 가 α·fidelity_loss 를 능가 못 함.
- **본 NetGain 의 perceptual validity 검증** = Step 6 (perceptual rating) 의 motivation.

### 5-4. Synthetic 의 B2 ceiling 이 G2 에서 부분 깨짐 — 단 negative finding
- Synthetic 에서 B2 가 best (catch-all dominant) 였으나 G2 에서 **B2 가 worst 그룹**.
- 단 G2 의 best 인 B5/B6 cl 도 absolute NetGain 음수.
- **catch-all 깨짐 = positive finding, absolute NetGain 음수 = negative finding** 의 혼합.
