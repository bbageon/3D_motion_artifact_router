## 4. 다음 turn 의 즉시 가능 작업

본 turn 의 work-window 가 끝나면 다음 turn 에서:

### Step 3: mgpt-clean env 생성

```
conda create -n mgpt-clean python=3.10 -y
conda activate mgpt-clean
```

### Step 4: CUDA torch 설치 (RTX 5090 활용)

RTX 5090 의 compute capability 가 9.0+ 또는 10.0 이므로 **cu126 또는 cu128 호환 wheel 필요**:
```
# 옵션 A: cu126 (PyTorch 2.5+)
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu126
# 옵션 B: cu128 (PyTorch 2.6+)
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu128
```

단 MotionGPT 의 다른 dependency (e.g. `pytorch-lightning==1.x`) 가 최신 torch 와 충돌할 수 있음. 호환 가능한 조합 확인 필요.

### Step 5-6: deps + HumanML3D

AGENTS.md §2-1 의 절차 그대로:
```
cd external_assets/MotionGPT_clean
pip install --upgrade "setuptools<58" wheel
pip install -r requirements.txt
# chumpy 실패 시 pip install chumpy==0.70 --no-build-isolation
pip install bert_score gdown
python -m spacy download en_core_web_sm

cd deps
git lfs install
git clone https://huggingface.co/google/flan-t5-base
gdown <smpl_id> -O smpl.tar.gz; tar xfz smpl.tar.gz
gdown <t2m_id> -O t2m.tar.gz; tar xfz t2m.tar.gz

cd ../checkpoints
git lfs install
git clone https://huggingface.co/OpenMotionLab/MotionGPT-base

cd ..
mkdir -p datasets
cmd /c "mklink /J datasets\humanml3d ..\HumanML3D"
```

총 8GB+ download. 시간 큼 (10-30분).

### Step 7: 공식 demo.py 실행

```
cd external_assets/MotionGPT_clean
conda run -n mgpt-clean python demo.py --cfg ./configs/config_h3d_stage3.yaml --example ./demos/t2m_mini.txt
```

결과 확인: `results/.../*.npy` 의 shape.
