# AR-082 - u*(s) 정책 지각 검증 A/B (사전등록)

Status: in-progress (2026-07-19 착수 — 사용자 승인 "진행해줘")  
Epic: Perceptual  
Priority: 🔴  
Parent: AR-081 (Strength-Q v1 "지지" — 단 "정책 작동" 표현은 지각 검증 전 유보)

## Goal

AR-081 의 u\*(s) 정책(λ\*=0.5, Q-state+gen)이 **적용하기로 결정한 모션**에서, 정책 보정본이
원본보다 사람 눈에 자연스러운지 blind 2AFC 로 검증. **"정책 작동" 표현 유보 해제의 관문.**

## 사전등록 (2026-07-19 — 결과 보기 전 고정)

### 표본 규칙

- 모집단: **holdout split 만** (정책이 학습에 본 적 없는 모션 — leakage 없음).
- **정책이 u\* ≥ 0.5 로 적용을 결정한 모션만** (적용 강도 질량의 ~89%). 사유: u\*=0.25 적용(적용의 ~11%)은 유도 변위가 작아 2AFC 시각 검정력이 없음 — **claim scope 를 "중간 이상 강도 적용분"으로 명시 제한** (숨기지 않음). STOP(52%) 의 정당성은 본 A/B 가 아니라 Cat-A(억지 적용 시 악화, E10)가 담당.
- v1·v2·v3 A/B 에 쓴 sample_id 전부 제외 (기억 오염 방지). 나머지에서 **무작위 20** (seed 20260729 고정) — worst-tail 아님: 정책의 실제 적용 분포를 대표.
- 각 pair 의 보정 강도 = **정책이 고른 u\*** (일괄 u=1.0 아님 — 정책 자체를 검증).

### 자극·blind

- 실속도 20fps 병렬 GIF, 좌우 무작위 (seed 20260730), answer key 분리, 평가자에게 정체 비공지.
- 정책 u\* 재산출은 학습 코드의 결정적 재실행으로 — 기존 결과 수치와 일치 확인 후 사용 (재현 검증 겸).

### 판정 기준 (기존 A/B 규율 동일)

- **지지** = 보정본 선호 **≥15/20** (이항 양측 p≈0.041) → "정책 작동" 표현 유보 해제 (단 b1 — 외부 공개급은 b2/b3).
- **기각** = ≤12/20 → 정책의 지각 계층 불성립 (1회 원칙 — 재시도 없음).
- 13~14 = inconclusive → b2 검토.
- 공시: pair 별 generator·u\*·shortfall 을 answer key 에 기록. 정책이 VQ 에 적용을 결정한 pair 가 포함되면 그대로 노출 (정책의 실제 행동 — 그로 인한 기각도 유효).

## Claim Boundary

허용: "holdout 에서 정책이 중간 이상 강도로 적용을 결정한 모션의 blind 지각 결과". 금지: STOP 결정의 지각 검증 주장 (Cat-A 몫) / u\*<0.5 적용분으로 일반화 / b1 을 외부 공개급으로.
